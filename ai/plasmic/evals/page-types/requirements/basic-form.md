# 新建优惠券

## 页面
路由 `/coupons/new`，从「营销中心 / 优惠券列表」的【新建优惠券】进入，菜单中隐藏。

## 图例
`[____]` 文本输入，`▾` 下拉选择，`[日期]` 日期选择，`ℹ` 字段提示。

## 页面线框
```text
┌──────────────────────────────────────────────────────────┐
│ 券名称[____]  券类型▾(满减/折扣/立减)  面额[____]元          │
│ 使用门槛[____]元  发放总量[____]张  有效期[日期]~[日期]       │
│ 使用说明[______________________________________________]   │
├──────────────────────────────────────────────────────────┤
│ 底部操作：[取消] [提交]                                     │
└──────────────────────────────────────────────────────────┘
```

## 字段规则
- 券名称：必填，最多 20 字。
- 券类型：必填，满减、折扣、立减三选一。
- 面额：必填，大于 0，最多两位小数；折扣券时为折扣率（0.1–9.9 折）。
- 使用门槛：选填，0 表示无门槛。
- 发放总量：必填，正整数，上限 1000000，ℹ 提示「发放后不可减少」。
- 有效期：必填，开始日期不早于今天。
- 使用说明：选填，多行，最多 200 字。

提交成功提示「优惠券已创建」并返回列表；失败提示错误原因并保留输入。
