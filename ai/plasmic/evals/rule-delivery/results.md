- 派生 inventory 保留 columnReason，避免合法来源证据在准备链路中丢失。

## Agent 行为证据及其边界

第一轮为两个隔离代理分别使用不可变基线/候选快照，完成同一组七案。实施者语义评分经独立 reviewer 复核：两者均 7/7。这个结果证明本组回归未观察到退步，**没有证明 Agent 总体成功率提高**。提示直接呈现了规则遗漏和检查盲区，且同一版本的七案共享上下文，不能据此推断自然任务中的稳定遵守率。

第一轮之后，同工作区并行修改加入全宽 3/4 列密度选择及 horizontal 默认。保留这些修改，并对合并后的文件重新运行完整回归和独立兼容性审查；这些新业务规则不计为本任务成果。候选代理按最终不可变快照继续复核七案，采用更新后的列数判据，七项均符合预期。此为同代理续审，**不是新的独立实验**。

可确定的效果是入口送达路径更直接，以及四类静态非法值不再被一致性检查放过。没有执行真实 Desktop 生成、Preview、保存重开或业务验收，也不能承诺所有 Agent 永不跳步。provider 时间和 token 用量未提供，记录为未知。
