# 页面结构设计评估

2026-10-30。本次评估对象为仓库内的 Plasmic skill、结构设计规范、原型 workflow、模板流程及规划脚本。原始输入见 [cases.json](cases.json)，独立 agent 的实际输出与复评记录见 [agent-output.md](agent-output.md)。

## 方法与边界

使用一个不继承主任务设计历史的子 agent，在离线环境下独立处理六个请求，并检查规划脚本衔接。提供 skill、当前参考文件和原始请求，不提供预期布局或主任务结论。首次评估后修正发现，再交给同一评估者回归；复评不宣称新的盲测。

这些是结构草案和执行路径评估，不是六个已生成的页面。未访问 Desktop/MCP、安装模板、检查实时组件契约或执行真实 Preview。单次候选评估不证明跨模型稳定性或相对于旧版的量化提升。

## 场景结果

| 场景 | 观察到的决策 | 离线判断 |
| --- | --- | --- |
| 编辑与实时手机预览 | 左编辑、右预览，非机械等宽；区分草稿预览与保存生效；只参考表单区域 | 符合需求，实际尺寸和契约待验证 |
| 明确要求下方展示试运行输出 | 保留上下布局和点击后刷新；不增加保存、自动运行或独立结果页 | 符合明确约束 |
| 已有外壳的类目工作区 | 复用壳，选择区块/抽屉候选；不复制无需求的 Tabs；给出实时读取路径 | 模板选择和获取路径合理，未假称已读取模型 |
| 仅改保存按钮文案 | 保留节点、位置和行为，不推导新的发布流程或重设计其他页面 | 修改范围受控 |
| 大幅拓扑监控 | 指标上方、拓扑为主、节点详情右侧；局部匹配信息模板，拓扑能力继续发现 | 未强套列表模板或伪造组件能力 |
| 三页先设计、只细化一页 | 保留所有区域草案，仅当前页细化组件；脚手架和清单均支持按页生成 | 阶段衔接可执行 |

## 评审驱动的修正

- 局部修改的最终验收明确限于受影响区域与流程，完整生成才要求完整项目验收。
- 页面类型明确覆盖输入后执行操作的工具页；使用真实动作语义，不默认增加保存或持久化。
- `scaffold --page` 和 `inventories --page` 支持逐页细化；独立复评实际验证只输出目标页清单和 intent，suite 仍引用完整源计划，其他草案及源文件哈希保持不变。
- 结构草案可在没有 live contracts 时完成；最终编排仍要求真实契约与模板证据。
- 生成/验收规则卡包含当前 `pageStructure`，结构判断不会只留在前期讨论中。
- 清理纵向根布局与预览必须放下方的冲突；组件默认值、共享滚动及来源证据约束继续保留。
- 详细组件政策通过规则卡按需读取；未提高资源或上下文预算。

复评在上述六个场景和实际执行的阶段衔接内，未发现剩余可操作的指令冲突。

## 验证方式

脚本回归使用 `python3 -B -m unittest discover -s ai/plasmic/scripts -p 'test_*.py'`；安装入口使用 `node --test packages/plasmic-cli/tests/skill.test.mjs`。资源包采用构建流程实际使用的 `validateReferences` 和 `validateComponentReferences`，检查链接、锚点、规则映射、组件覆盖及阅读预算。

- Python 完整回归：524 项通过，62.450 秒。
- CLI skill 安装/同步测试：20 项通过。
- 202 个资源的引用、规则和组件覆盖校验通过。
- prototype 直接引导阅读量为 204,060 bytes，低于既有 212,992 bytes 上限；mustRead 为 12,172 bytes。没有扩大预算。
- `git diff --check` 通过。

新检查覆盖结构缺失、未决字段、非法/重复区域锚点、横向布局保留间距约束、当前页预检不要求兄弟页完成、完整预检拒绝草案、逐页清单不生成兄弟页产物。自动检查只证明记录完整和引用一致，不能判断布局合理性；这部分保留在逐页视觉和交互评审中。

通用 `skill-creator/quick_validate.py` 不识别现有 `compatibility` frontmatter，当前文件与未修改的 HEAD 均因此返回失败；该字段未改动，也未为通过通用校验删除运行环境约束。

重跑场景时，将 cases.json 和候选 skill/引用交给新的独立上下文，输出到临时目录，不提供本报告或旧输出。结合原始需求检查实际设计决策，避免以字段数量或自称通过作为质量评分。
