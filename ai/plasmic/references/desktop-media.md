# Desktop media and export

Read only for reference capture, asset creation/editing or file export. Discover exact live tool schemas and configured services; these capabilities do not replace editable model reading or native project coding.

8. import_image uploads an explicit absolute local raster file to NAS storage and returns src/width/height. It converts to PNG and does not preserve animation. Use that source in a registered Image component via insertHtml or changeElement. read_image returns a WebP preview (quality 85, maximum long edge 2048, no upscaling; sourceImageSize preserves original dimensions) from an exact image src observed by snapshot_layout with view:"images". Sources not present in the design are rejected. Raster data URLs and authenticated NAS images are supported, up to 10 MiB; vector sources require a screenshot.

9. export_design saves static PNG, JPEG, WebP, PDF or HTML at an absolute outputPath with a matching extension. Files are never overwritten. HTML includes rendered markup and CSS, has scripting disabled, and is not editable React source or an interactive standalone app. Image links may still refer to NAS/external assets. PNG/PDF embed the rendered visual. Save editable project data with execute save.

12. get_screenshot elementUuid crops visible nodes and returns a WebP preview (quality 85, long edge at most 2048). fullResolution:true returns original-size lossless WebP; sourceImageSize retains original dimensions. reference_browser maintains an isolated external reference page for load/capture/read-only CDP; only the reference page is accessible, never the Studio debugger. capture_browser captures an HTTP(S) reference page or selector as a WebP preview and a reference to sanitized styled HTML; fullResolution:true requests lossless original-size pixels. Read HTML through read_result if needed; import_reference with action editable passes it internally into a separate artboard without exposing it to the agent. make_vector authors SVG paths and boolean geometry, optionally importing an SVG asset; SVG source is returned by reference. SVG assets are replaced as source, not edited as native Studio path nodes.

13. export_pages combines ordered artboards into one PDF. export_code saves its bundle and returns fileCount plus a files reference; read_result pages the complete manifest without exporting again. The skill's [code-generation workflow](workflows/codegen.md) reads models and generates native project code; it does not call export_code.

14. get_image_service_status returns configured/model without credentials. generate_image supports generate/edit/remove_background/replace_background and requires image-service.json (baseUrl/model/apiKey) in user-data. Choose a service supporting the action. Returns a new original PNG plus WebP preview; import_image uploads it. No provider is configured by default.

reference_browser returns only its read result; import_reference returns the explicit import receipt; get_state omits history, UI appearance and prior imports. Selection retains its selector and target dimensions; capture/CDP can inspect styles when needed. Import receipts retain created identities and warnings. make_vector returns pathCount, total area and aggregate bounds; its SVG reference preserves all path source. Static geometry is not evidence of Preview behavior. Design presets supply palette/layout values; read existing tokens and registered theme contracts before applying them.

vectorize_image locally traces raster files to SVG assets (at most 1 megapixel, best for flat artwork). search_stock_images returns Commons raster assets with license/source/attribution; preserve those requirements when using an asset. readVector returns an SVG source reference and asset identity through MCP; read_result retrieves the source; updateVector edits sanitized geometry while preserving node/asset IDs (shared asset references update together). createCanvas/createArtboard create native freeform canvases at real viewport sizes; findEmptySpace finds non-overlapping positions in four directions; navigateCanvas selects that canvas/frame before snapshots. Native Studio normalizes canvas origin after placement, so read returned coordinates. Cross-component moves and editing descendants of opaque third-party React components remain governed by Studio component/slot contracts. Built-in AI is a later scope. Report verified behavior and limitations explicitly.
