# 项目代码规范

## 优先级与项目形态

当前需求、目标仓库规则、已安装包类型和真实宿主契约决定实现；本规范提供缺省规则。读取相邻模块以确认接入方式，不能把历史实现中的问题视为规范，也不能借生成页面改造无关代码。

独立应用可拥有 AppShell、Router、Provider 和主滚动；子应用复用宿主的登录、菜单、顶栏、路由、请求、语言/方向和内容间距。业务原型为展示而拥有的 AppShell，在已有宿主中映射为内容区域；子应用不创建第二套 shell 或登录。Provider 保留已有 prefixCls、主题、locale、direction 和上下文反馈机制，不逐页重复初始化。

## 目录与依赖

沿用现有目录约定。新工程或没有约定的模块可采用以下职责；只创建实际需要的文件：

```text
src/
  pages/<Module>/
    index.tsx          页面组合、查询/分页、共享上下文协调
    model.ts           领域类型及纯映射
    styles.ts          页面样式
    components/        拥有独立状态/交互的私有业务区域
  service/             类型化接口调用
  components/          确实跨模块复用的 UI
  hooks/               已有或确实复用的 Hook
  i18n/                项目词条（有国际化要求时）
mock/                  项目机制支持的开发 Mock
```

页面不是只返回一个承担全页职责的空壳 `Workspace`。独立 Tab 若有自己的查询、请求与编辑流程，可由私有组件负责；父级保留导航和共享上下文。拆分依据独立行为和生命周期，不依据设计节点数或行数。

运行时依赖方向为 `pages → service / shared components / hooks`；service 不依赖 React、UI、toast，公共组件不反向依赖业务页面，纯映射/工具不发请求或弹提示。不要增加循环 barrel、万能 `mode` 组件、全局事件总线、通用表单引擎或将来可能用到的扩展接口。

组件 PascalCase，私有文件命名服从模块语义与目标约定。使用已验证的 alias；只对复杂纯逻辑拆 validation/diff 等文件，不创建空文件四件套。跨页面复用有真实消费者后再提取。

## 类型与数据模型

分别定义需要的接口 DTO、查询、Form 值、展示模型与保存 payload；简单且相同的类型无需重复。明确 ID/code 与 label、枚举值与翻译、日期类型与提交格式。字段必填/范围/可编辑性来自业务契约，不能根据样例推断全部规则。

使用严格 TypeScript、类型化 Form/Table 和联合类型描述编辑模式。避免 `any`、双重断言、`@ts-ignore` 或为了过编译把关键类型改为可选。`0`、`false`、空字符串、null、undefined 各按契约处理，不使用 `value || fallback` 吞掉合法值。类型断言不能代替运行时校验未知输入。

DTO 到展示、Form 到 payload 的映射在明确边界执行。保留实际实体 ID、版本号与字段语义，不生成假的更新时间/操作人，不以名称替代标识；复杂归一化保持纯函数，便于测试业务边界。

## 组件、主题与布局

复用顺序：目标公共业务组件 → 已安装库公开 API → 必要的本地实现。库 API 以目标版本类型为准，不复制参考项目的依赖版本，不默认升级或安装另一套 UI 库。

样式沿用目标方案；目标已有 antd-style 时使用 `createStyles` 与模块 `styles.ts`，不新建并行 LESS/CSS Modules 体系。优先公开 props、Theme Token、语义化 `classNames`/`styles`、className；不覆盖 `.ant-*` 或自定义 prefixCls 的内部 DOM 类名。

布局优先 Flex/Space/Row/Col/Card；间距由一层负责，避免双 padding/边框。按真实页面保留密度、列顺序与宽度、长文本策略、表格横向滚动和可达操作，不把示例尺寸推广为通用硬限制。子应用使用宿主主滚动，不机械套 `100vh`；弹层可有局部滚动。独立应用明确主滚动所有者。

## 国际化、权限与环境

复用项目 i18n 命名空间、格式工具、locale/direction 联动；不建页面私有翻译字典，不逐层传 `t`。只给实际要求的语言补齐词条，UI locale 不限定业务多语言内容范围。RTL 使用逻辑间距/对齐，代码/URL 局部 LTR 有语义依据；图标按钮有可访问名称，保留焦点与键盘操作。

权限标识来自需求/后端/已有权限清单，不根据角色名、用户名或样例按钮猜测。受控入口在权限未加载、失败或无权限时隐藏；业务状态不允许操作时 disabled 并说明原因。只读约束覆盖入口和提交路径，后端仍独立鉴权。

Mock 遵守目标机制，默认不进入生产行为；新工程的网络 Mock 明确开关且只在开发环境加载。静态演示可用本地 fixture，但不得宣称真实请求成功。认证、环境地址、构建常量来自目标配置；不把某个宿主的全局变量、国家或端点写入通用生成规则。
