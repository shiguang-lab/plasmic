## Color value

Read this wrapper's value, format, showText/showTextSwitch, allowClear, disabled, trigger and onChange contract. Inspect its serialized returned color rather than storing a native Color object or assuming v6 completion callbacks. Theme-owned semantic colors remain theme choices unless the user actually configures them as business data.

## Acceptance

Verify initial/changing/cleared values, the required display/storage format, custom trigger and disabled state. Check Form ownership, popup bounds, actual stored value and saved callbacks; do not infer persistence from the displayed color swatch.
