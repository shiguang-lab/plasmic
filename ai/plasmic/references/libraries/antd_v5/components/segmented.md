# Segmented

Library: [Ant Design v5](../index.md).

| Registered component | Registration key |
| --- | --- |
| Segmented | `plasmic-antd5-segmented` |
| Segmented Option | `plasmic-antd5-segmented-option` |

## Compact choice

The wrapper uses options or optionsSlot through useSlotOptions. Segmented Option nodes keep stable values and editable children. Read value/defaultValue, size, disabled, block and onChange from this library; native labels do not establish a new route or field schema.

## Acceptance

Test both option branches when used, initial/change/disabled states, long labels and actual value callback. Keep view state separate from business data and use Tabs when real panel semantics are required. Save/reopen option values and bindings; do not insert v6 option metadata into this wrapper.
