# Switch

Library: [Ant Design v5](../index.md).

| Registered component | Registration key |
| --- | --- |
| Switch | `plasmic-antd5-switch` |

## Boolean value

This v5 Switch exposes checked/defaultChecked, disabled and onChange(checked). In Form, retain its actual checked field binding. An immediate backend toggle requires the consuming workflow's verified permission, pending and failure policy; the component does not save the boolean by itself.

## Acceptance

Exercise false/true, initialization, controlled/uncontrolled values, disabled behavior and the actual submitted field. For immediate actions, test one mutation and required failure recovery. Keep a meaningful label and keyboard operation, then save/reopen bindings.
