# Carousel

Library: [Ant Design v6](../index.md).

| Registered component | Registration key |
| --- | --- |
| Carousel | `plasmic-antd6-carousel` |

## Sequential slides

Use Carousel when the requirement calls for sequential slide content. Keep actual slide nodes in children and read autoplay, arrows, dots, infinite, effect, dotPlacement and afterChange(slide). Required business instructions and primary actions must not be accessible only in an automatically disappearing slide.

## Acceptance

Test multiple real slides, controls, boundaries/looping, visible-slide callbacks, variable-length content and the intended fixed/natural slide geometry. Enable autoplay only when approved for that content and preserve usable keyboard controls. Remove default Slide 1/Slide 2 content and verify the delivered nodes after save/reopen.
