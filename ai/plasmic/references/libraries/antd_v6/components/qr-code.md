## Encoded business value

QRCode encodes the actual value, not its display label. Read size, color/bgColor, icon, canvas/svg type and active/expired/loading/scanned status. The state must come from the actual workflow; rendering or displaying a scanned style does not prove a user completed an external operation. Replace the registration's sample URL before delivery.

## Acceptance

Verify the encoded destination/content, usable size/contrast, supported icon and the required loading/expiry/recovery transitions. Test real decoding when the workflow requires scanning and keep adjacent instructions readable. Save/reopen the actual value and state bindings.
