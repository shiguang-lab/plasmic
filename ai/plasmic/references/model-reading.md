# 页面模型与组件契约读取

## 读取真实模型

按 [MCP 读取契约](desktop-mcp.md)定位 tree、读取实例 properties 或注册 contract。代码生成与验收用 `view:"full",depth:"all"`；省略字段/子引用不代表空内容：

| 范围 | 需要取得的信息 |
| --- | --- |
| 页面 | UUID、名称、路由、根布局、引用组件、视口/响应式变体 |
| 节点 | 实际组件身份、Props、Slot 内容及顺序、文本、条件显示、重复表达式 |
| 数据与状态 | 类型、初值、派生值、绑定、状态所属范围、样例数据 |
| 交互 | 事件签名、目标状态/动作、参数、打开/关闭/提交/跳转流程 |
| 视觉与资产 | Token、主题、样式/断点、图标、图片/SVG 来源 |

从页面根递归读取引用的自定义组件与 Slot，包括非活动 Tab、关闭的 Drawer/Modal、隐藏分支和重复模板。对于 opaque 第三方组件，读取公开注册契约和提供方文档；无法取得的内部行为标为未知。渲染 DOM 不替代组件的业务语义。

[渲染检查](desktop-inspection.md)负责几何、截图与 Preview。布局索引不是模型 UUID，静态截图不执行交互；只读任务不得通过修改 open/activeKey、初值或保存设计获取隐藏内容。无法观测的状态标为未知。

## 根据当前实现决定目标代码

生成代码时，逐组件核对设计端 MCP 注册 metadata/公开 wrapper 契约，以及目标可用的导出、版本、类型和实现。确认 props、默认值、Slot、事件参数和受控/非受控状态，保留内容与行为的所属关系。注册名不等于 npm 导出名，Slot 不保证对应同名 prop；按[组件契约与复用](codegen/project-code.md#组件契约与复用)决定 JSX 和业务逻辑。

不使用 Pencil、其他编辑器或旧项目的预设组件转换表。设计端和目标端 API 不同，按实际实现完成必要转换；没有证据时记录缺口，不猜字段或生成看似等价的组件。原型模拟数据不证明后端 API 存在，编辑状态不定义真实权限。

搜索区、表格、行操作优先使用目标已有公共业务组件，但先核对目标 API。Plasmic Overseas wrapper 与目标 `@react/ui` 或本地组件不保证相同；所需能力不存在时按目标库公开 API 实现需求。运行 callback、格式化与数据请求依据业务需求编写，截图不能提供这些契约。

使用真实图标组件，避免 Unicode 符号冒充图标。日期等非 JSON 值按目标控件和 API 的真实类型处理；不要把展示字符串直接当保存值。布局、主题、条件与重复按已读取的信息实现，不引入通用模型解释器。

## 运行边界

保留业务语义，去除编辑占位、选择/reveal 状态、registry、模型 UUID 查询与临时 canvas overrides。无需因采用 Plasmic 设计而引入 Loader、SDK 或同步配置。英文 PascalCase 设计节点名可辅助命名，不要求每个节点生成一个组件。

解析图片/SVG 的真实来源、尺寸和使用权，按目标工程资源规则接入。需要认证的 NAS URL 或 data URL 不保证生产可用；不可访问时报告依赖，不替换为无关素材。保留业务语言和要求的响应式行为；未确定业务流程列为契约缺口。

## 读取完整性与实现来源

先读取项目概览，再按实际 schema 分批读取目标页面与引用组件，记录已读取 UUID，避免循环重复。元素子树只能证明该范围；需要页面状态/交互/查询时读取所属完整组件。发现工具结果被截断或绑定引用缺失定义时补读，仍不可取得时将该项标为未知；不能从空字段推断业务能力不存在。读取期间源设计变化时重新取得受影响模型和截图，不把不同版本拼成一个验收输入。

MCP metadata 不是源码下载接口；codeComponent 的 importPath/importName/defaultExport 仅提供导入线索。目标实现依据来自授权的应用源码、已安装包类型/源码或提供方公开文档，记录来源与版本；不读取 Plasmic App、Desktop/Studio 或其提取的内部实现。公开契约不足时保留调用与缺口，停止依赖工作并完成独立部分。查询定义不证明生产 API 或凭据存在。

只读解读只需说明模型与注册契约，不需要建立目标工程或取得无关 npm 包。模板解释从 catalog 选定来源后读取对应实时组件及嵌套内容；catalog 的 Slots/版本是索引记录，需要核对。
