界面方向

首页使用紧凑的桌面窗口栏、224 px 侧栏和三列设计缩略图。设计文件直接进入视野，不设置工作台横幅、业务指标或快捷管理区。中性灰作为底色，紫色只用于创建和选择。文件卡片采用“画布预览 + 文件名 + 位置信息”，没有独立卡片底座和常驻权限徽章。

参考 Figma 文件浏览器对文件、文件夹与账户入口的组织，以及 pen.dev 的无限画布与 AI 编辑结构。本方案保留 Plasmic 的项目与空间模型，不复制其他产品的文件格式、文件夹层级或未实现能力。

数据模型与后台约束

“设计文件”是现有 ApiProject 的展示称呼；不新增 File 数据表，不复制持久化模型，不改变 projectId、权限、路由、Props 或编辑器契约。最近更新严格使用 updatedAt，不冒充最近访问、最后打开的页面或光标位置。缩略图为设计示例，正式实现只使用已有项目缩略图；缺失时显示中性画布占位，不合成虚假业务内容。

顶栏只展示“文件”入口，不暗示已实现多文档标签页。窗口控制使用桌面宿主提供的原生行为；Web 环境不绘制 macOS 控制。所有文件沿用现有可访问项目集合，当前团队仅控制侧栏空间与管理菜单，不暗中改变全局列表范围。

原有功能V4 入口实现边界
最近、全部项目、搜索、排序、网格 / 列表最近更新 / 所有文件，工具栏复用 AllProjectsPage、useProjectsFilter；搜索文件名与空间名，不提供跨页面内容检索。视图切换不改变筛选范围。
个人项目、团队项目、空间个人空间与团队下的空间列表复用已有 workspaceId，不新增“文件夹”资源。个人空间不承诺所有内容必然私有，权限依现有授权。
空白创建与项目模板新建设计弹窗 / 模板页沿用 createProject、cloneProject、clonePublishedTemplate；只列出有创建权限的目标空间，保留名称验证、失败重试和提交中禁止重复提交。
AI 描述需求新建设计 → 描述需求当前创建链路未验证 AI 生成项目。本版提供清楚说明与“创建空白文件”退路；输入需求不得被当作已经执行。直接生成能力接通前不启用生成按钮、不展示伪预览。
项目重命名、配置、复制、移动、模板标记、删除文件卡片省略号 / 上下文菜单沿用 ProjectListItem 与 dashboard-actions 的权限、套餐 / 席位限制；删除保留确认。移出 Dashboard、下载仍依既有授权与 DEVFLAGS.demo 条件展示。图中普通菜单不是所有权限角色的固定菜单。
成员、团队分析、用量账单、组织设置、新建工作空间团队名称旁的省略号菜单保留原页面和能力开关；团队分析不新增未经核对的指标。组织创建、切换在团队下拉中。
内容库、数据源、成员权限、空间设置、Studio UI 配置、移动 / 删除空间空间名称旁省略号；空间页右上角省略号复用现有空间资源与管理流程。只读角色隐藏管理动作；删除、移动不因入口整理跳过原限制。
账户、外观、语言、AI 连接账户菜单 / 左下角设置原设置子页继续可达。UI 标签走共享语言包；业务内容与组件英文注册契约不随 UI 翻译。
模板中的页面、区块、弹层模板分类 / 选择目标文件后进入画布插入项目模板用于克隆；局部模板使用既有画布插入。分类目录按实际可用配置显示，示例不代表组织模板设置已启用。
无限画布、组件、AI 编辑、评论、历史、预览、分享、导出、发布打开文件后继续使用原编辑器本次不删除、不改造这些功能。新建 / 打开仍使用既有项目路由。
