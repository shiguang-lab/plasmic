原设计问题推荐设计实现成本
项目为大边框横向条目，难形成视觉识别默认卡片网格，名称／工作区／修改时间组成简洁信息层；列表视图适合名称检索。两条真实项目，无虚构项目。前端布局与本地视图偏好，无新增实体。
只有顶部按钮能启动新项目，空态缺少明确下一步顶部按钮、网格创建卡、个人试验场空态共用一个创建动作。复用已部署 Blank project 入口。没有添加名称、模板、AI 等创建参数。
新建弹窗大而空锚定创建按钮的轻量弹层，单一 Blank project 行动与取消。更换呈现容器；保留原 handler、作用域、取消语义、焦点管理及 Escape 关闭。点击后的原有流程继续执行。
侧栏品牌、账户、组织关系较散账户置顶，组织与工作区树集中；辅助入口底部；侧栏及组织树可以折叠。导航状态在前端保存；不改变组织成员或工作区关系。
组织页的工作区、项目与 CMS 层级松散每个工作区成为完整资源分组。分享／新建／更多留在分组头，CMS 在同组底部可见。复用当前组织页取得的工作区、项目、CMS 集合，不合并新的资源实体。
工作区缺少稳定的位置感组织 → 工作区路径，项目／数据源标签、分享／更多操作固定在上下文。复用原路由和标签参数；个人试验场保留自身上下文。
搜索、排序分散；所有项目难按工作区收窄同一浏览工具栏整合工作区筛选、搜索、两种原排序和网格／列表切换。按现有 workspaceId 过滤当前可访问项目；不创建新 API。筛选不扩大授权范围。
菜单／分享弹窗风格像管理后台锚定上下文菜单、紧凑的成员分享面板；危险动作分隔。复用现有 action handler、权限判断、邀请与角色模型。

卡片封面与真实缩略图

当前 ApiProject 没有 thumbnail 字段，部署客户端也没有项目预览图。本图组的 REQ075 / AT 是从项目名称生成的静态封面，不表达项目类型、运行状态或画布内容。封面可以立即由前端生成；无封面数据也能稳定渲染。完整名称用于可访问名称与悬浮提示，视觉行过长时截断。

真实画布缩略图是值得后续增加的能力，但不能只在列表塞一张图就算完成。推荐单独实施：保存后的后台任务渲染约定的主页面，产物按 projectId 与版本记录写入受权限保护的存储，通过受保护的只读资源返回。默认封面始终作为失败、未生成或无可渲染页面的回退；不新增“用户自选封面”功能。

原有功能逐项保留

范围入口与契约
导航所有项目、我的试验场、组织、工作区、新建组织、文档、组织帮助、账户设置、退出登录均保留。设置仍含账户、偏好、个人令牌、可信托管应用，本次不重画其正文。
项目浏览名称、修改时间、所属工作区来自原项目对象。点击打开原项目。重命名仍靠原操作；配置项目、复制项目、移至工作区、设为工作区模板、删除项目保留，菜单按权限显示。Admin Templates 是普通项目，不是模板中心。
创建仅当前部署账户的 Blank project 创建起点。顶层全部项目继续使用原个人工作区上下文；工作区内创建使用原 workspaceId。没有使用未部署的更复杂仓库创建表单。
复制副本名称和目标工作区两项；未选目标时提交禁用。可选择的目的地按原权限结果取得，不展示虚构空间。
组织／工作区组织成员数与项目数、新建工作区、组织设置；工作区项目、数据源、CMS、新建 CMS、分享。工作区更多仍为移动到其他组织、删除工作区。CMS 属于工作区，在数据源标签内。
分享邮箱邀请与查看者、评论者、内容编辑者、设计者、开发者全部保留。默认开发者。所有者为实际成员状态，不混入可授予角色。继承的组织访问仍通过组织管理。
其他权限／账号分支当前图片只画实际账户可见菜单；实现继续依赖原权限分支，不把图片中所有动作强制开放给所有用户。其他数据源、套餐和功能开关分支保留原行为，不凭当前空态删除。
