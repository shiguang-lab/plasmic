设计判断

原稿的工作台与全部项目使用同一套项目分类，造成重复；“最近 / 我的 / 团队”混合了排序、所有权、空间三个维度。新版首页只展示最近更新与创建入口，全部项目负责检索与管理，工作空间承载项目、内容库和数据源。个人空间通过明确入口与筛选保留。

原稿标题声称搜索项目、页面与资源，但已读实现只按项目名和空间名过滤；新版准确标注搜索范围。首页采用最近更新时间，不声称是最近访问或上次编辑页面。缩略图没有真实截图时应使用示意占位，不伪造项目内容。

组织切换与工作空间列表分开。全部项目沿用现有跨工作空间权限范围，不由当前组织名称暗中缩小结果；顶栏明确说明“所有我有权限访问的项目”。该页面面包屑使用全局“我的项目总览”，避免歧义。组织管理项按现有权限与产品开关显示。

功能核对与后台依据

能力处理方式读到的代码依据 / 实现要求
项目查询、搜索、排序、网格 / 列表保留并集中到全部项目；首页复用最近更新结果。AllProjectsPage.tsx、useProjectsFilter.ts；getProjects / listProjects。当前客户端过滤排序，不假设服务端分页。
空白项目、项目模板保留名称、目标工作空间、模板选择与错误重试。NewProjectModal.tsx：createProject、cloneProject、clonePublishedTemplate。目标空间限有创建权限的空间，不能只相信前端筛选。
AI 描述需求保留需求入口与输入设计；待接入状态允许改走空白创建。不展示生成前页面预览。当前 NewProjectModal 未见 AI 项目生成分支。若启用，需串联项目创建与 AI 任务，处理权限、输入保留、失败恢复和防重复创建；应通过真实能力状态控制入口。空白创建不得暗示已执行输入需求。
重命名、配置、复制、移动、模板标记、删除保留项目菜单；危险操作独立确认。复制复用名称与目标空间表单。ProjectListItem.tsx：renameSite、cloneProject、setSiteInfo、isUserStarter、deleteSite。移动仍需保留席位 / 套餐检查；复制、删除等权限按现有条件判定。
移出我的 Dashboard、下载项目保留现有条件化菜单，不在普通所有者菜单一律显示。ProjectListItem.tsx：removeSelfPerm；下载受 DEVFLAGS.demo 控制。“移出”仅移除自身权限，不等于删除项目。
工作空间、内容库、数据源提供三个清晰的空间内入口；原内容条目编辑、模型结构、内容库设置继续沿用。WorkspacePage.tsx：getWorkspace、getProjects(byWorkspace)、listCmsDatabasesForWorkspace；WorkspaceDataSources.tsx 为现有入口。数据源示例不表示实际已连接，也不添加未确认的健康状态。
成员、组织设置、工作空间设置、账单、团队分析保留导航与原功能页面；组织 / 空间权限区分。图集中不重复绘制未改页面。dashboard 现有 TeamMemberList、TeamSettings、TeamBilling 与原稿对应页面。团队分析具体指标与服务尚未在本次核实，按现有实现与开关保留入口，不新增指标承诺。
账户、外观、语言、AI 连接、帮助通过底部设置、个人账户与帮助保留；设置子页沿用原设计。不改编辑器主题与业务页面语言约束；UI 标签走语言包，组件契约保留英文注册词。
页面 / 区块 / 弹层模板不与可克隆项目混为一类。保留分类入口，选择项目后进入画布模板插入流程。项目模板来源沿用 starters / 工作空间模板；局部模板目录是否启用必须读取实际配置与模型，不能只依据设计示例。此次未修改管理员模板或业务原型。
无限画布、预览、分享、评论、历史、导出、发布打开项目后仍走原编辑器和交付入口；本次不重做或删除这些页面。原 48 图中 11–35 的编辑器与交付范围保留。本次未验证这些功能的运行状态。

新增设计的落地成本

首页最近更新卡、工作空间分组入口、搜索空态、骨架屏和重试反馈主要是现有数据与状态的 UI 重组。无需新增协作动态、收藏、通知中心、回收站、项目发布状态聚合或业务 KPI 服务。AI 生成项目是明确待接入的流程；真正启用前要验证服务链路。

验收

render.cjs 渲染 20 张 1600 × 1000 PNG，检查浏览器异常、页面尺寸、内容区溢出与弹窗边界。人工检查首页、模板创建、项目菜单并修正首页网格嵌套问题。此验证仅证明设计稿可渲染，不代表应用功能已实现。设计稿保存在独立 dashboard-v3，原 48 图及应用代码保留。
