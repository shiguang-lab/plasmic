共享交互结构

区域统一规则
编辑器顶部左上项目与保存状态；右上撤销、重做、预览、分享、更多及用户。常规状态不改变位置。
左侧工具选择 / 平移 / 插入 / 图层 / 资源 / AI。图层、插入和 AI 共用左面板位置，不叠加第二个导航体系。
右侧属性设计 / 交互 / 数据；无对象选择时显示画布设置。组件名称、Props、Slots、枚举和事件沿用英文注册契约。
无限画布各页面的位置固定；总览缩放 25%，聚焦 54%。专注画布与总览保持相同视口，只收起面板；恢复面板不重排页面。
视口操作右下统一缩放与适合全部；聚焦状态显示返回总览；专注状态显示恢复面板。
AI底部显示当前作用范围；执行时发送替换为停止。进行中与完成状态共享同一请求与目标，新增列仅出现在确有修改的状态。
预览独立顶部工具栏：返回编辑、页面选择、桌面 / 平板 / 手机、评论、分享。右侧评论属于评审外壳，业务 Drawer 属于白色页面。
分享与交付顶部分享始终打开同一弹窗，使用分享预览 / 导出代码 / 发布应用三个标签。
新建项目同一弹窗使用描述需求 / 使用模板 / 空白项目三个标签。项目名称、工作空间和底部创建按钮共用位置与措辞。
主题深浅色复用相同 DOM、内容与尺寸，只改变 CSS 变量。业务页面持续使用自身主题。
状态表达只读禁用修改操作；保存失败不显示已保存；Drawer 临时展开不改变 open 的保存值。

页面范围与交付

登录、注册、重置密码沿用现有界面，不参与改造。页面清单覆盖项目工作台、模板、新建、编辑器关键状态、预览评审、交付、个人与团队设置、内容库和开发者文档。内部运维页面与认证回调不在本次产品交互范围内。

所有示例数据均用于设计评审。账单、权限、AI 服务、CMS 和工程交付行为需在实现阶段对照实际能力；设计图不代表已接入。

验证包括浏览器脚本错误、画幅尺寸、面板越界和共享控件坐标/文字一致性。截图来源可直接在本地浏览器打开，不依赖在线服务。
