核心决定：把操作放回它所作用的对象旁边

功能最终位置行为与理由
页面 / 组件 / 画板组左侧「文档」中的三类导航统一搜索、创建、重命名、文件夹与右键操作；切换对象后进入图层。当前文档菜单显示所属画板组。
组件插入左侧「插入」项目组件与已安装库同时可发现；点击或拖入后在右侧编辑真实 Props / Slots / Events。
组件安装「插入」底部常驻「组件商店」商店用宽面板展示库、依赖与安装状态；完成后打开已安装组件库，避免自动插入不明组件。
组件库管理「插入 → 管理库」及「资源 → 已安装库」同一个管理界面：查看组件、引用、导入、升级检查与移除；没有重复管理逻辑。
全局资源搜索插入面板搜索框跨组件、模板、素材检索，按类型与来源分组。无搜索时才按分类浏览。
总览 / 专注左侧当前文档的导航菜单仅改变画布呈现。与「隐藏面板」分开，避免一个按钮兼任三种操作。
面板 / 外观 / 画布显示顶部紧凑的「视图」图标面板开关、点阵、边界、主题、减少动态效果。专注模式可随时恢复面板。
缩放右下角只含缩放比例、放大缩小、适合全部与适合选区；移除页面、画板组和设置入口。
评论 / 预览 / 分享 / 代码 / 发布右上固定动作区各自独立入口；评论展开右侧协作面板。发布前检查、分享权限和代码集成不混用。
问题 / 帮助问题在左侧工具轨；帮助在项目菜单问题检查复用左侧面板，不叠加浮层；数量以真实检测结果为准。帮助包含快捷键、文档与支持。
项目 / 分支 / 历史 / 高级左上项目名与保存状态旁项目级操作归属项目；低频设置可以收纳，日常制作能力保持直达。
令牌 / 预设 / 动画 / 字体 / 断点左侧「资源」按设计基础、素材和依赖分区；数据源与全局上下文放项目设置，实例数据在右侧数据页签。

统一交互规则

左侧只显示一个主面板，切换保留查询和展开状态；重复点击收起。工具提示延迟 400ms，点击即隐藏，焦点环只在键盘导航显示。主面板使用 120ms 小幅淡入，系统减少动态效果时关闭动画。弹层 Escape 返回触发器，安装过程中不因误点外部丢失状态。深浅主题使用同一布局与语义颜色，业务画布不随编辑器主题变色。只读保留浏览与预览；不可用的安装、编辑、发布动作显示权限原因。

组件名、Props、Slots、Events 保持注册英文，UI 标签可本地化。编辑时临时展开组件不修改初始业务状态。组件安装失败保留条件并可重试；升级、移除展示依赖引用与明确确认。版本号和库列表来自实际元数据，设计稿中的内容仅作示例。

布局与验收边界

1600px 标准稿：工具轨 56px、左面板 280px、右面板 264px；画布占据剩余空间，底部 AI 与缩放互不遮挡。1180–1399px 时减少顶部文字、保留图标提示；更窄窗口采用一次展开一侧面板，评论替换属性面板。发布与商店使用受视口约束的宽弹层，不挤进菜单。

本轮交付为新的编辑器设计方案，尚未替换产品全部布局。组件安装完整链路仍需在具有实际组件与编辑权限的项目中验收；不能以此交互样稿代替真实能力验收。
