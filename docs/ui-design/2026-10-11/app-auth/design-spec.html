App 登录与窗口操作

采用铺满窗口的连续背景。登录区域与页面融合，不使用独立标题栏、顶部导航条或登录卡片外框。Logo 与产品名紧接 macOS 窗口按钮；语言与外观入口位于内容区右上角，距顶部 72px、右边缘 108px，与右侧内容边缘对齐；独立于窗口操作和品牌所在的一行。它们直接放在连续背景上，不形成独立顶部栏。

窗口操作

场景位置与行为
macOS左上角保留原生关闭、最小化、全屏按钮，不增加底色条。生产实现使用系统窗口控件，设计图中为位置示意。
Windows右上角保留最小化、最大化、关闭；语言与外观入口位于其下方的内容区，品牌位于左上角。使用平台窗口控件或标题栏覆盖机制，保持系统窗口行为。
拖动窗口顶部 52px 空白区域透明可拖动；双击行为遵循系统设置。按钮、语言、外观等交互区域排除拖拽。
系统全屏窗口控件的隐藏与显露遵循系统行为；内容持续铺满可用区域。

右侧信息层次

右侧直接从标题开始，不单独放置大尺寸状态图标。状态含义由标题、步骤、进度提示及按钮传达。登录入口依次展示标题与说明、项目 / 组件模板 / 分享协作三组价值信息、浏览器登录提示、主按钮和新用户引导。进入登录后，价值信息区换为“打开浏览器—完成登录—返回工作空间”三步进度，清楚区分已完成、进行中与待完成。异常时展示重新开始后的步骤，不声称未知步骤已经完成。重新登录保留原目标页提示。

登录文案与流程

主按钮统一为“登录”。页面只显示用户需要的下一步与操作结果，不展示身份供应商、授权协议、内部地址或技术解释。底层继续复用现有登录与授权流程。

状态App 显示与操作
idle登录入口，无独立用户名、密码或注册表单。
opening正在打开浏览器；禁用主按钮；可以取消。
waiting等待登录完成；可以重新打开浏览器、复制登录链接或取消。
copied显示“链接已复制”；不展示原始授权地址。
success短暂显示成功，自动返回原目标路由，不增加确认步骤。
error区分登录取消、等待超时、连接异常；可以重试或返回入口。
会话过期提示重新登录，显示登录后返回的页面；不承诺恢复未保存的编辑。
账户只读显示个人资料与登录状态；“管理账户”进入浏览器，账户安全沿用现有服务。

一致性与验证

主视觉、状态容器、主按钮、语言与外观入口在所有登录状态间保持相同位置。深浅色使用同一布局与同一画布视口，仅改变配色。语言与外观入口在 macOS 与 Windows 上保持一致，均位于系统按钮下方的内容区；Windows 品牌位于左上角，主内容位置保持一致。

本次交付为设计稿及本地状态切换示意。窗口按钮不实际关闭或最小化浏览器，登录不发起真实请求，复制状态不复制真实授权地址。生产实现中的窗口、账户管理和退出登录动作需绑定已有能力；UI 文案需进入共享语言包。
