# 组件复用建议：实现与测试

2026-11-05，源码实现完成。建议随原编辑回执返回，Agent 再评估一次是否替换；自定义 UI 可以保留，不自动改设计，不增加生成式模型请求。

## 调用方式

设计编辑必填 `reviewContext`，由共享 Zod 契约生成 MCP JSON Schema。单次编辑放在 `input` 内，批次放在外层，只提交一份：

```json
{
  "reviewContext": {
    "purpose": "Switch customer information panels on the same page, keeping selection and content synchronized without route navigation"
  }
}
```

只有 `purpose` 必填，最多 500 字符；交互与明确限制自然写在功能说明中，不要求段落格式。单次与批次使用相同结构。Agent 不提供区域列表或操作编号；程序从实际操作和编辑回执定位目标、合并重叠范围，最多检查五处，超出时报告 `partial`。缺字段、空白、错误类型或未知字段在修改前拒绝，返回 `operationExecuted:false`。

只有用户明确要求本次功能自行实现、不要使用现有注册组件时传 `customOnly:true`；其余情况一律传 `false`，遗漏也按 false 处理。单纯要求自定义样式或交互、已有自定义代码、Agent 自行选择手写均不构成 true。该选择作用于整次调用；如果只针对部分功能，应将其他编辑放到另一调用。这个 boolean 由 Agent 判断，MCP 不核实聊天原文或语义。

参数结构由程序约束，功能语义由原有 Agent 提炼。字段说明包含正反例，优先使用简短英文功能表述匹配当前英文组件注册；用户引述与界面文案保持原文。没有新增翻译调用。整批多个无关功能共用说明可能降低匹配精度，程序不承诺将一句话自动拆成各个目标的独立意图。

## 实际执行

HostFrame 编辑工具 → 现有 TopFrame API → Desktop preload / IPC → Node 检索与缓存 → 唯一 llama.cpp CPU 进程。Go MCP 负责传输，不加载模型。

- 采用 EmbeddingGemma 2 文本 GGUF `UD-Q4_K_XL`，768 维，固定权重哈希与 llama.cpp commit；CPU 两线程，空闲 15 秒退出。
- 项目自己的可复用组件及已安装的直接、传递依赖都参与检索，包括未在页面使用的组件；以当前模型和有效注册为准，不查询最新商店版本，不限制组件库。
- 用途与接口分片，BM25 与向量融合，候选最多三个。返回精确身份、契约摘要、匹配证据和待确认项；提示读取 Skill 与当前完整契约，Agent 判断是否适用。
- 向量按模型处理签名与实际文本哈希持久化，账号隔离。重复打开复用缓存，只重算变化片段；查询向量另有 128 条内存缓存。
- 常用公共注册预置 126 个组件、260 个向量，逻辑大小 807,040 字节。它们只提供向量缓存，不使未安装组件成为候选；其他组件走同一增量路径。
- 后台索引每次处理一个片段，用户输入时暂停提交，前台查询优先。运行中的单片推理不能立即抢占。
- 手动操作、纯文字/样式/布局修改、已由注册组件承载的功能、明确保留自定义及已经提示的区域跳过查询。实际新增原生功能控件仍检查，不因旁边已有标准组件而免检。
- 编辑提交后，在同一次扫描内完成一次分析再结束扫描。可用性检查、缓存同步与检索共享五秒预算；超时或失败保留已成功的编辑，不迟到补发建议。批次只有一次扫描和分析，替换后的节点也继承已提示标记。多目标复用同一功能说明，查询向量缓存避免重复推理。
- 同一编辑会话/调用者、同一页面或组件定义内，同一候选组件只提示一次。删除后重建、重写功能说明不会让同一候选再次出现；不同候选和其他页面正常提示。同页另一独立区域也不重复提醒已经介绍过的候选。工具返回后由 Agent 自行读取规则，不在编辑扫描内等待 Agent。

## 本机数据

Apple M4，24 GiB，macOS 26.6.2，Node 24.20.0；纯 CPU 两线程。以下是生产 Node/native/cache/search 路径，**不包含 Electron 画布渲染、完整 MCP 往返或 Agent 思考时间**。未清操作系统磁盘缓存。

| 项目 | 实测 |
| --- | ---: |
| 公共注册预置缓存：126 个组件全部可用 | 30.7 ms，零文档推理，未启动模型 |
| 101 份冻结文档无缓存首次后台索引 | 58.98 秒，154 次文档推理 |
| 仅修改一个片段 | 921 ms，仅一次文档推理 |
| 三个独立 Node 进程重新打开缓存 | 23.5–26.1 ms，零文档/查询推理，未启动模型 |
| 已有缓存、启动新模型后的第一条查询 | 450 ms；之前的运行时校验另计 96 ms |
| 后续 30 次查询，来自 10 种意图 | P50 0.81 ms，P95 33.43 ms |
| 含两条预热的 32 次查询 | 10 次实际查询推理，22 次查询缓存命中 |
| 查询阶段 RSS 检查点 | 原生模型 360.3 MiB；独立 Node 探针 139.0 MiB |
| 索引完成后 RSS 检查点 | 原生模型 389.5 MiB；独立 Node 探针 115.5 MiB |

查询缓存使重复查询的中位数很低，不能据此声称新摘要推理只需 0.81 ms。RSS 是阶段采样，**不是连续峰值，也不是整个 Desktop 的内存**；Node 探针包括测试与目录对象，不能直接视为 Electron 主进程增量。首次磁盘读取或繁忙机器可能更慢；五秒是程序预算，不是所有查询必达的耗时承诺。

无缓存的完整索引不放在编辑等待中。公共缓存可立即使用，自定义组件在后台准备，未齐时按 `partial` 报告覆盖率。原始数据见 [Node/native 测量](native-final.json) 与 [实际注册测量](registrations.json)。`runtime.json` 为测量时资源清单，当前准备的资源见 [runtime-current.json](runtime-current.json)；公共缓存本次仅补算一个变化片段，仍为 126 个组件、260 个向量。

## 组件描述与召回

执行当前 Antd6 与 Overseas 的真实注册函数，捕获 126 个注册组件。补充或修订 30 个根级英文用途描述（19 个源文件），有用途描述的组件由 11 个增至 39 个。已有的 Descriptions、SearchForm 等描述保留。注册 Props、Slots、默认值、事件和其他元数据经前后比较保持一致；仍有 87 个组件缺根级用途描述，不能声称目录已全部完善。

小型诊断集有八个可复用场景与两个特殊自定义场景：

| 同一检索流程 | 前三候选命中 | 特殊自定义误提示 |
| --- | ---: | ---: |
| 描述完善前，英文结构化语义 | 6 / 8 | 0 / 2 |
| 描述完善后，英文结构化语义 | 8 / 8 | 0 / 2 |
| 描述完善后，仅中文语义 | 5 / 8 | 0 / 2 |

这十条样本参与过调试，**不是独立验收集**；不能将 8/8 宣称为生产准确率。英文输入优先来自这组诊断结果，中文仍合法但召回较弱。全部输入、候选、阈值和计数见 [注册测量](registrations.json)。该归档保留原始分字段诊断输入；当前探针已将同一检索文本直接存为 `purpose`，文本和后端算法没有因此改变，不把历史时间重标成新一次测量。

另外，同一历史冻结集的 37 个正例在当前生产分片、阈值与融合流程中命中 30/37。四个负例中，直接后端调用仍会对“仅间距”“纯文案”返回候选；正常编辑路径通过前置判断跳过这两类，单测覆盖此行为。两个特殊自定义负例没有建议。历史原生探针的 33/37 采用不同检索流程，不能混用为本次结果。旧证据的 110 个哈希已重新校验，未修改历史结果。

## 验证与复现

完整回归记录包含 Studio 七个测试文件 169 项、Desktop 581 项通过。本轮字段命名与描述另验证了 30 项 Studio 测试和 1 项真实 MCP 协议测试，输出见同目录 `flag-contract-*.log`；TypeScript、Go 测试、生成契约一致性与 `git diff --check` 通过。

验证命令、版本、最终源码与证据哈希在 [manifest.json](manifest.json)，原始输出在同目录日志。测试覆盖参数校验、实际原生编辑成功后分析失败、整批扫描生命周期、跨窗口转发、身份校验、缓存复用/损坏/增量、查询调度、取消与防循环。

防循环回归使用真实原生编辑工具，模拟首次插入后连续三次“删除再插入”，每次重写用途说明，并让检索端始终返回相同候选。修复前建议数为 `[1,1,1,1]`，修复后要求 `[1,0,0,0]`，每次编辑均成功；另验证不同候选与其他页面仍能提示。这是工具链回归，检索端为固定测试返回，不是实际长会话 Agent 行为测量。新会话、不同调用者、新页面或新候选可产生新建议，不能据此保证 Agent 在任意任务中绝不循环。

在仓库根目录准备当前平台运行时：

完整工作区先从共享契约与真实注册生成 MCP schema 和公共检索文档；Desktop 独立构建读取已提交的生成文件，不依赖完整 Studio 安装。准备脚本固定模型/源码版本并生成公共向量；相同输入重复准备复用缓存。`desktop/scripts/package.mjs` 已纳入运行时准备和资源打包。开发运行需先执行准备命令；编辑过程中不下载权重。

尚未重建或安装 Desktop 整包；使用新必填参数需要 Studio 与 MCP 同步构建。尚未测实际 Studio 索引期间的拖拽帧率、Windows/Linux、长会话 Flash 模型填参及采纳率。这些不能由当前单测和本机检索探针替代。
