# AI 编辑区域反馈（本地 App）

## 行为

- Studio 的 AI/MCP 仅在修改设计、批量编辑及安装或升级组件库时显示活动反馈。读取、查询、会话识别、上下文获取、选中、导航、滚动、检查、校验及保存等辅助调用保持静默，包括调用失败。
- 内置 AI 的范围编辑共用同一反馈机制；范围内的只读操作也保持静默。
- 页面编辑覆盖对应画板，元素编辑通过渲染节点定位对应模块。移动/复制同时标识源和目标；没有独立 DOM 的节点使用最近可渲染祖先，并注明“所在区域”。
- 区域标签和画布顶部状态显示目标名称、正在编辑或编辑完成。失败立即清除该操作的反馈，错误通过工具返回交给 agent，不显示失败提示或红色扫描。
- 同一节点共用一个扫描层，按编辑请求引用计数；单次批量操作重复指向同一节点只计一次。React key 使用节点身份，新的引用加入或旧引用释放时复用原扫描 DOM。
- 成功的短操作最少扫描 1.6 秒；长操作保持提示直至结束，结束扫描后静态完成状态保留 400 毫秒。工具返回不等待动画。各请求独立释放引用，计数归零移除扫描层；失败不保留动画或完成计时器，关闭 Studio 取消全部计时器。
- 同一区域仍有操作运行时，优先显示运行中的编辑；其他请求的完成或失败不会覆盖或移除它。
- 区域随真实 DOM 位置更新，裁切到画板及内部滚动容器。边框和标签随画布缩放保持可读尺寸；减少动态效果的系统设置使用静态提示。
- 提示不拦截指针、不改变选中状态，不属于 Site 数据、撤销记录或画板导出内容。

## 验证

在 `platform/wab` 运行：

```bash
pnpm test --project studio src/wab/client/copilot/activity.test.ts src/wab/client/components/canvas/CopilotActivityOverlay.test.tsx src/wab/client/copilot/prototype.test.ts src/wab/client/copilot/scroll-element.test.ts
```

覆盖读取与查询成功/失败静默、SVG 读取失败静默、范围内只读调用静默、实际批量编辑反馈、错误返回与立即清理，以及并发引用、计时器、DOM 复用、区域裁切和滚动辅助调用。
