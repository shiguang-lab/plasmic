# AI 读写区域反馈（本地 App）

## 行为

- Studio 的 AI/MCP 在画布上用亮蓝色（`#1677ff`）标记成功的本地节点、页面和 SVG 读取，查询标记当前结果页的首个匹配节点。设计修改、批量编辑及安装或升级组件库使用主题主色。内置 AI 的范围编辑共用这套反馈。
- 读取项目清单、依赖或组件注册契约，以及无匹配的查询，保持静默。会话识别、上下文获取、选中、导航、滚动、校验及保存等辅助调用也保持静默。
- 页面编辑覆盖对应画板，元素编辑通过渲染节点定位对应模块。移动/复制同时标识源和目标；没有独立 DOM 的节点使用最近可渲染祖先。
- 读取和编辑共用细边框、1 px 扫线与渐变拖尾，颜色区分操作。拖尾峰值随 Studio 外观调整，浅色 18%，深色 22%。失败立即通过工具返回交给 agent；已显示的扫描完成当前轮次后清除。
- 同一节点共用一个扫描层，按编辑请求引用计数；单次批量操作重复指向同一节点只计一次。React key 使用节点身份，新的引用加入或旧引用释放时复用原扫描 DOM。
- 成功的短操作最少扫描 1.6 秒；长操作保持提示直至结束。达到收尾条件后，可见扫描等待 CSS 当前轮次结束，再用 400 毫秒淡出边框。业务请求完成、失败或取消均不等待动画；请求引用释放后，已经显示的扫描仍由动画层负责收尾。连续请求复用同一区域扫描并撤销待关闭状态。关闭 Studio 或切换画布销毁旧反馈；减少动态效果时使用静态反馈，不等待不存在的动画事件。
- 同一区域仍有操作运行时，优先显示运行中的编辑；其他请求的完成或失败不会覆盖或移除它。
- 区域随真实 DOM 位置更新，裁切到画板及内部滚动容器。边框随画布缩放保持固定的屏幕宽度；减少动态效果的系统设置使用静态提示。
- 提示不拦截指针、不改变选中状态，不属于 Site 数据、撤销记录或画板导出内容。
- 原生 Preview 的整页快照用蓝色扫线覆盖当前预览视口。传入 `scopeRef` 时，只扫描目标与视口和滚动容器相交的区域。目标完全滚出可见区域时仍可读取已渲染内容。内容断言和状态检查保持静默。切页、刷新或关闭时清理扫描，预览截图和灵动岛的镜像底图均不包含这层反馈。

## 代理光标

- 编辑页的实际编辑目标同时驱动代理光标。连续操作复用光标并平滑移动；长操作期间保持可见，结束后闲置 5 秒再淡出 1.5 秒。失败立即清理；读取扫描不会创建光标。
- 编辑页和原生 Preview 复用光标运动与外观。外部 Agent 的光标显示当前操作所属 MCP 连接的名称（例如 Codex、ChatGPT）；无调用者身份时使用本地化的 AI 助手标签。光标采用当前主题主色；图标与标签在画布和预览视口缩放时保持屏幕尺寸稳定。
- MCP 初始化时从客户端 `clientInfo` 注册一次调用者，生命周期连接关闭时释放。后续内部 RPC 仅关联调用者会话标识，不向工具业务参数添加身份字段。排队和执行中的操作各自保留调用者，画布与 Preview 不使用全局当前 Agent，也不将身份写入设计模型。
- Preview 的点击、悬停、输入、选项选择、按键和滚动显示目标位置。点击和悬停使用既有命中检测得到的真实点，真实输入继续通过既有 DOM/CDP 链路执行。
- Preview 光标跟随目标的滚动和位置变化；目标移除或隐藏、切页、关闭和失败会清理。截图期间隐藏反馈层，截图结束后恢复，捕获失败也会清理。
- 光标标签和图标放在独立 Shadow DOM 中，不进入业务文本检查；反馈层不拦截指针，也不改变页面业务状态。系统减少动态效果时，位置直接更新并停用浮动。

## 验证

在 `platform/wab` 运行：

```bash
pnpm test --project studio src/wab/client/copilot/activity.test.ts src/wab/client/components/canvas/CopilotActivityOverlay.test.tsx src/wab/client/copilot/prototype.test.ts src/wab/client/copilot/scroll-element.test.ts
pnpm test --project studio src/wab/client/copilot/agent-cursor.test.ts src/wab/client/components/live/PreviewFrame.test.tsx
```

在 `desktop` 运行 `node --test tests/preview-runtime.test.cjs`，覆盖预览读取扫描、真实交互目标、失败清理和截图隐藏/恢复。

覆盖节点读取、查询、SVG 读取及实际批量编辑的反馈、空查询和失败静默，以及并发引用、计时器、DOM 复用、区域裁切和滚动辅助调用。
