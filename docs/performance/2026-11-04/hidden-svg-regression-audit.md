# 隐藏 SVG 的十画布退化复核

2026-11-04。**没有复现“跳过隐藏 SVG 会固定增加约 49ms”的退化。现有证据更支持进程/环境波动；尾部仍有不确定性，不能因此宣称零成本、稳定提速或全部验收通过。** 现已恢复跳过隐藏 SVG 的实现及相关回归测试，保留原构造和流光；未替换客户端。恢复不改变本文对尾部不确定性的判断。完整样本、环境记录、统计结果与源码校验见 [JSON](hidden-svg-regression-audit.json)。

## 旧结果为什么不足以判定代码退化

上一轮十画布全部完成中位数 B 为 4022.05ms、D 为 4071.15ms，差 +49.10ms。B 是修改前候选，D 只增加跳过隐藏 SVG；均含此前的宿主动画启停和底部线框修复。

D3 同一进程的四次热打开依次为 3983.00、4050.40、4485.50、4345.40ms（原始浮点值见 JSON）。Studio 模块导入仍约 92–95ms，慢样本主要表现为画布初始化及渲染变长，例如初始化阶段最大值从约 294–296ms 升至 407/367ms，首次渲染阶段最大值从约 188–190ms 升至 215/283ms。阶段包含等待与重叠，不能相加归因整页差值。

这些样本都是相同载荷、13 个组件、10 个完成的画布、87 次接口请求、49 条缓存资源记录，项目修改计数为零。没有发现慢样本增加了业务内容或额外请求。但旧轮未记录关键期间的窗口/CPU/电源状态，不能追认当时是哪项环境因素造成变慢，也不能单凭少建节点的逻辑排除所有代码效应。

## 复测设计

直接使用同一冻结 B/D 构建，不重新编译，不修改运行时代码。实际加载入口的 source map 已核对：B 没有返回 null 的分支，D 有该分支；两个 rendererHash 与上一轮一致。

- B：`9f36fd98228caf8738ff1f4d8dcf8bf1eea10c3e58888f0bdd239dfef0f7665d`。
- D：`b64446c22a36268390d23539afdc41b63d836af2b4ae1fc08d1a815a27879a2a`。

按 B1/D1/D2/B2/D3/B3/B4/D4/B5/D5/D6/B6/D7/B7/B8/D8 执行八对交错实验，每进程六次打开，前两次预热。每侧 32 个热样本、8 个首次打开样本，共 16 个进程、96 次打开。使用全新标签的隔离 profile、相同不可变十画布夹具、相同请求保护和就绪条件；不混用上轮样本。

本代理没有同时运行构建、单测、trace、独立原生探针或关键路径中的定时采样。通过 caffeinate 在整个轮次防显示器/系统休眠；点击前先等待窗口可见且聚焦。窗口焦点/显示、电源和热状态变化通过事件记录；CPU/负载快照只在点击前和指标收集后采集。初次就绪和最终收集记录实际页面可见性。诊断 harness 位于独立私有目录，未修改工作区或原冻结 harness。

统计以进程为单位：比较每对进程各自四个热样本中位数的 D−B 差，固定种子、20000 次配对 bootstrap，报告中位差及 95% 重采样区间。预设只有区间下界大于零且至少 6/8 对变慢，才支持持续性退化。全部样本保留；区间不是零成本或未来机器表现的保证。

## 相同代码与环境干扰

事先将八个 B 进程拆为两组：A 为 B1/B4/B5/B8，A2 为 B2/B3/B6/B7。两组完全相同代码，用作同代码噪声检查，并非另外增加的独立实验样本。全部完成的进程中位数拆组差为 +13.00ms，区间 [−110.35, +58.00]ms；B 各进程中位数从 3941.15 到 4100.75ms，跨度约 159.60ms。相同代码的进程差异已足以影响几十毫秒级比较。

所有采集到的热状态为 nominal，没有挂起、锁屏、热状态或限速事件，没有隐藏/最小化，初次就绪页面均为 visible，Studio WebContents 的 backgroundThrottling 为 false。但窗口并非整个轮次始终聚焦：B5 的四个热样本在点击至全部完成的区间内发生 blur；D 的热样本未记录此类关键期间事件。不能把窗口启动时聚焦等同于整个加载阶段没有失焦。

另在 D2 第六次打开，全部完成为 4969.20ms，结束快照出现三个不属于诊断 App 进程集合的 Node 进程，CPU 约 69%–78%。B5 慢样本附近也记录到高 CPU Node/XprotectService。快照不是持续 CPU profile，不能据此精确分摊耗时或证明某个进程是旧 D3 的原因；但可以确认整机负载和前台状态并未完全受控。没有擅自结束这些进程。

因此全量反向结果也不能直接宣传为稳定提速，尤其不能把本轮反向差值全部归功于代码。

主分析不删除任何数据。另依据窗口事件而非耗时大小，排除受干扰的整对 B5/D5，做明确标记的敏感性分析；其余七对、每侧 28 个热样本。

## 当前判断与边界

可以确认的是：**上轮 +49.10ms 不能认定为代码固定退化；复测没有复现该退化，且实测环境存在足以影响结果的干扰，波动解释更符合现有证据。** 不能确认的是：旧轮两个慢样本的具体外因、所有机器零开销、P90 一定不变慢，或已经通过完整交付门槛。

归因审计阶段没有修改运行时；随后恢复了跳过隐藏 SVG 的实现及其生命周期测试。纯 CSS 和 Worker 原型仍未采用，没有替换客户端。若继续验证尾部，应使用可保持前台且不运行其它高负载工作的专用环境，保持构建、夹具和指标不变，避免通过反复重跑直到某次通过来决定交付。
