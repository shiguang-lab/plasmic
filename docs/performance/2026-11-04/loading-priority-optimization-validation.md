# 按优先级执行的加载优化实验

后续对第 1 项的退化归因复核见 [隐藏 SVG 退化复核](hidden-svg-regression-audit.md)：上轮约 +49ms 未稳定复现，当前证据更符合测试波动；P90 仍不确定。下面保留当轮门槛与撤回决定，不将验收失败等同于已证实代码退化。

2026-11-04。依次验证跳过隐藏 SVG、纯 CSS 构造和 Worker + OffscreenCanvas。**两个运行时候选都未通过预设的整体加载门槛，本轮运行时修改已撤回，客户端未替换。** 保留新增的初始化失败后重试回归测试；本轮开始前的候选代码及底部线框修复均保留。完整正式样本、候选源码存档、构建哈希、原生探针和功能结果见 [JSON](loading-priority-optimization-validation.json)。

## 第 1 项：跳过被覆盖的 SVG 子树

在 `BrandLoading` 所有 Hook 调用后、构建遮罩字符串和 JSX 前，宿主加载状态为禁用时直接返回 null。没有改动外层启动动画、品牌路径、构造资源、流光、就绪条件或计时标记。揭示后仍按正常路径创建本地 loading，禁用时取消动画、释放 URL，重新启用时重新播放。

GP 实际内层 Studio 框架的独立采样确认：揭示前本地 SVG 最大数量由 1 降为 0。最初两个基于文档内 bootstrap 的探针未覆盖 document.write 创建的内层 Studio 文档，两侧均记录零，不能用于证明收益；改为浏览器进程采样实际框架，取得修改前正对照后才继续验收。资格探针与正式计时分开，没有删减正式性能样本。

候选通过隐藏/恢复/重播、取消/URL 回收及初始化失败后重试回归，也通过 GP、十画布的真实离线功能回放。性能结果中 GP 中位数略好，但十画布全部完成和尾部未达门槛，故没有保留该运行时改动。

## 第 2 项：纯 CSS 可行性

Electron 45.2.1 可见窗口中，用实际品牌路径和遮罩分别测试 SVG 描边、CSS motion path、填充裁剪，以及 transform 对照。先设置原生动画，再主动阻塞 renderer 主线程 1200ms，从浏览器进程捕获画面；另在无阻塞时确认各动画确实正常运行。

| 小样 | 无阻塞的 6 次捕获，不同画面数 | 阻塞中的 9 次捕获，不同画面数 |
| --- | ---: | ---: |
| SVG strokeDashoffset | 6 | 1 |
| CSS offsetDistance | 6 | 1 |
| clipPath inset 填充揭示 | 6 | 9 |
| transform 位移对照 | 5 | 9 |

只检查是否在阻塞中继续推进，不能将两列不同采样数解释为 FPS。该小样中的填充与位移可继续，沿路径运动与描边仍冻结，不能同时满足保留当前构造细节和阻塞中流畅播放的要求，未进入产品。此结论仅针对实际测试的小样，不代表所有 CSS 构造方法都不可能。

## 第 3 项：Worker + OffscreenCanvas

私有原型沿用实际 SVG 路径和渐变，在 Worker 中以 Path2D、归一化虚线轨迹和渐变遮罩重绘同一构造。流光沿用 HTML 合成动画；主线程不注册逐帧回调。停止、减少动态效果与重复播放释放 Worker、Canvas 和 Blob URL。原型仅存在于私有实验和随附 JSON 中，没有引入生产依赖或保留另一套生产实现。

深色原生探针通过：主线程各阻塞 1200ms 时，构造与等待流光均捕获到七个不同画面，构造彩色像素变化范围 7087，完成后的彩色像素数 11371，主线程 JS 帧回调为零。重复播放、卸载、减少动态效果与深色线框通过。GP 与十画布功能回归也通过。

另在 599/1496/2394/3159ms，将 Worker 输出与现有无损 WebP 的对应四帧独立对照：RGB 通道平均绝对误差约 0.032/0.087/0.099/0.059（0–255），低于事先设定的 4。它验证代表帧的几何、颜色和构造一致性，不宣称逐像素完全相同或已比较全部动画帧。

Worker 单次原生探针首次绘制就绪为 13.3ms。此前 WebP 单次探针为约 4.5ms，来自不同独立运行，不能相减宣称稳定增加 8.8ms，也不能当作整页增加量。现有 WebP 已使用浏览器原生解码，换 Worker 并不自动移除显著的主线程逐帧工作；Worker 启动、矢量绘制和画布提交仍有成本。正式整页对照没有显示可接受收益，因此原型淘汰。没有把整页差值全部归因于 Worker 启动，未拆分每个子步骤的独立成本。

- S：实际历史三张骨架卡片展示，恢复范围见 [骨架基线验证](loading-skeleton-baseline-validation.md)，保留同一当前业务初始化，非整个历史客户端版本对比。
- B：本轮开始前的候选，宿主隐藏动画停止播放但仍创建静态 SVG，含底部线框修复。

- W：D 加 Worker 构造原型。
