节点选择与属性面板优化验证

2026-11-02。当前实现把立即生效的画布焦点与面板使用的已提交选择上下文分开，减少属性计算、关闭菜单的初始化及 DOM 测量工作。代码已在独立用户目录的 Electron 生产构建中验证；尚未替换 `/Applications/Plasmic.app`。

**具体问题与改动**

- 面板属性行原先反复读取实时焦点，重复解析组件上下文、查找渲染实例和复制数据环境。`InspectorSelection` 捕获 ViewCtx、组件上下文、节点和重复实例 clone key；属性上下文和数据环境按这个选择共享计算。画布渲染版本更新会使活动缓存失效，选择切换时停止旧上下文读取。
- 画布焦点立即更新，面板在画布获得绘制机会后提交最新选择。连续选择取消旧的待提交任务。旧属性回调在实际执行事务时校验所属上下文，避免排队的编辑写入已经离开的节点。
- 属性菜单和字段标记原先在未打开时也生成完整弹层主题。现在只在菜单内容挂载时计算；尺寸和数据建议菜单关闭时只保留 Downshift 需要的隐藏列表，不创建弹层滚动条。
- 尺寸选项使用已有 `VirtualListScrollbar` 作为唯一滚动视口；外层 `DropdownOverlay` 只负责主题、定位和裁剪。修正根节点 override 的 props/ref 传递，定位引用和主题类实际落到 DOM。
- 面板外层共享 `Scrollbar` 保持挂载。等待期间使用不可压缩的最小高度占位，并禁用内容的浏览器滚动锚定，避免卸载正在聚焦的字段时滚回顶部。新内容提交后恢复自然高度。
- 内容编辑入口只需判断是否存在裁剪区域，找到第一个后停止扫描；实际进入内容编辑仍完整枚举。DOM 映射只在祖先确实裁剪该方向时读取对应 client 尺寸。

当前属性控件仍在选择提交后完整挂载；没有隐藏已配置属性或按屏幕可见性延迟提供功能。组件 props、slots、默认值和保存模型不增加另一层配置格式。

**性能方法**

对照构建使用同一工作区，将本次修改的运行模块替换为修改前源码；source map 读回检查变化范围。两个构建均使用同机、同窗口、同项目「REQ-018 权益管理」、同页面「券模板管理」和同修订 254。等待启动模型和包加载稳定后，通过真实 `ViewOps.tryFocusObj(..., { exact: true })` 选择六类节点，每类 5 次，共 30 次；每次校验编辑器上下文身份和目标节点。采样期间未启用 CPU profiler，也未并行运行构建或测试。

完整面板时间是开始选择至 pending 解除、当前面板 DOM 完成的观察时间；同步时间包含 `changeSelection()` 引发的反应式工作。rAF 只表示浏览器获得绘制机会，不等同于实际显示器呈现时间。P95 使用 30 个样本的 nearest-rank 值，样本数不足以推导总体置信区间。

- 17 个相关测试文件、109 项测试通过：选择提交、重复实例、失效回调、数据上下文、DOM 映射、内容编辑、菜单键盘交互和主题等。滚动锚点调整后另外复跑面板测试，2 项通过。
- `pnpm --dir platform/wab typecheck` 通过；生产 `rsbuild build` 通过；修改的运行模块定向 ESLint 为 0 errors，19 项既有 warnings；`git diff --check` 通过。
- 原生鼠标点击按钮的 Disabled 属性，确认保存模型中的 `disabled`、画布实际按钮及属性开关一致，其他节点参数未变化；undo / redo / undo 都恢复对应模型和运行时状态。
- 同一任务内连续选择输入框、下拉框和文本，立即画布焦点为最后目标，面板只提交最后目标；旧 provider 的编辑权限失效。
- 面板滚动至 100px 后连续选择，pending 和最终状态都保持 100px，使用相同滚动 DOM；面板中只有一个共享滚动视口。
- 原生点击尺寸输入打开选项：菜单在视口内，暗色背景符合主题，只有一个虚拟列表滚动视口；Escape 关闭。
- 原生内容编辑入口展开 4 个裁剪相关元素，退出后清理目标、展开属性和临时样式。
