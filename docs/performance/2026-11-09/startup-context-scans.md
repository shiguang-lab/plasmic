# 启动上下文与样式/字体扫描：第 4、5 项验证

2026-11-09。**第 3 项已放弃，第 4、5 项本轮均未合入产品。** 当前保留已验证的启动引用修复及按画板加载组件库。所有原型位于私有冻结源码；没有替换已安装 App、修改生产服务或持久化线上项目。脱敏数据和指纹见 [测量数据](startup-context-scans.json)。

**第 4 项：缩小启动 API 的账号上下文。**

在 NAS 0.6.10 服务容器的独立 Node 进程中，调用实际部署的 getAppCtxData，与复用已授权 Project 的项目级裁剪原型比较。当前 appctx、team-plans、DbMgr 源码 SHA-256 与部署文件一致。只允许 SELECT 等事务控制语句，逐次回滚；未改路由或数据库。完整读取与裁剪读取按 ABBA 重复四轮，首轮预热排除，每侧六个样本。裁剪保留现有工作区、所属团队及相关自身权限，逐条与完整响应校验字段一致。

| 服务端阶段 | 完整上下文 | 项目级裁剪 |
| --- | ---: | ---: |
| 方法耗时中位数 | 22.0 ms | 22.4 ms |
| SELECT 数 | 9 | 8 |
| JSON 字节 | 34360 | 3855 |
| gzip 字节 | 5892 | 981 |
| 团队 / 工作区 / 自身权限数 | 2 / 3 / 79 | 1 / 1 / 2 |

数据库合计仅 4 个团队、7 个工作区、95 条权限。首个未复用项目授权的原型需要 14 次 SELECT、约 42.5 ms；复用后虽减少一条查询，方法耗时仍约 22 ms，没有测出服务端加速。gzip 仅少约 4.8 KiB。当前试用状态检查为空实现，不能作为节省的工作量。

这些是数据库方法阶段，**不含 HTTP、IAM、真实网络、完整启动关键路径或 App 内存 A/B**；已授权 Project 的读取耗时单列在原始样本中。独立 HTTP 探针未取到可用的既有会话值，未触发登录或部署候选。不能把响应少约 30 KiB JSON 当作 App 工作集下降。

裁剪响应还需要在组织切换、项目转移、工作区选择等入口补齐完整目录；当前原型只验证服务端成本与记录字段，不是完整的延迟目录实现。对本账号不建议优先推进第 4 项。未测大型账号，也不推断大型账号一定无收益。

**第 5 项：样式和字体扫描。**

首个原型按整个 Site 的引用图筛选依赖，功能通过，但十画板样式构造阶段由约 5 ms 增至 33 ms，新增引用分析抵消了减量，停止采用该版本。

最终候选复用画板已有的模型引用查询；构造阶段保留完整依赖 CSS 变量，具体依赖组件规则延迟到目标文档使用时生成，并按不可变依赖缓存。保留原依赖与组件顺序、主题/Token/图片变量、全局 Context、默认/fallback/未激活分支。自定义 Host、全局动态表达式、非 hostless 组件、注册函数及代码库保留全量规则。已有依赖更新路径重新建立缓存。画板数量和缓存策略没有变化。

字体构造本身仅约 3 ms，最终候选保留完整扫描、字体状态与选择目录；只在 installAllUsedFonts 中按 family 去掉重复样式表注入，不丢弃 FontInstallSpec 的 variants 或状态数据。GP 目标文档字体链接 **4→2**，两个唯一 URL 完全一致。依赖 CSS 从 **97446→73075 字符**，约少 25%；这不是等量 App 内存收益。

最终候选重新独立执行耗时与自然内存 ABBA：每侧两个进程，每进程六次打开、排除前两次预热，共 16 进程、96 次打开，计时和内存各 32 个暖样本。两侧相同 Host/canvas/ReactWeb 运行时；无 debugger、trace、强制 GC 或功能探针。活动工作集在就绪后额外等待 1.5 秒读取，打开阶段峰值按 100 ms 采样。表内为中位数。

| 场景 | 首画板揭示 ms | 全部画板渲染 ms | 活动总工作集 MiB | 打开采样峰值 MiB |
| --- | ---: | ---: | ---: | ---: |
| GP 单画板 | 1453.8→1448.0 | 1412.3→1405.7 | 1317.2→1307.4 | 1317.1→1307.4 |
| 十画板总览 | 1324.6→1326.2 | 3380.9→3380.3 | 1537.4→1532.7 | 1538.6→1536.8 |

GP 首画板仅少约 5.8 ms，十画板全部渲染几乎持平，不宣称明显加载加速。活动总工作集本轮观察到约少 9.7 / 4.8 MiB，但暖样本范围明显重叠。十画板两个对照进程中位数为 **1541.4 / 1524.0 MiB**，两个候选为 **1541.1 / 1523.0 MiB**，成对差距不足约 1.1 MiB。不能从池化中位数的差异认定稳定内存收益，也不将构造阶段减少的时间直接当成首屏收益。

第 5 项仅有较小的资源减量；现阶段不建议以“加载提速”为目的合入这套缓存与延迟生成实现。字体去重可独立评估，但本轮没有将其微小收益单独归因。第 3 项未参与最终对照，两侧活动 ViewCtx 仍分别为 1 和 10。
