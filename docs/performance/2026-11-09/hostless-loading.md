# 按画板加载组件库：正式实现与验收

2026-11-09。第 2 项已接入正式画布初始化链路，沿用第 1 项启动引用修复。源码与本轮生产模式诊断构建指纹一致。构建和回放没有替换已安装 App，也未写线上项目。脱敏结果与源码、运行时指纹见 [测量数据](hostless-loading.json)。

**加载规则。** 仅内置 Host 的业务画板按模型引用选择组件库；Studio 隐藏注册文档保留项目完整注册契约。选择范围覆盖画板容器、全局 Context、组件间接引用、参数默认值/预览值、Slot/RenderExpr/VirtualRenderExpr、表达式 fallback、未激活变体、TplRef、富文本 NodeMarker、子/父组件及 render-prop 允许的组件类型；沿用模型现有强/弱引用元数据，补齐库声明的传递依赖。

自定义 Host 保留全部项目依赖库。内置 Host 中出现非 hostless 注册组件、访问 window/globalThis 的表达式，或者项目及传递依赖中注册函数/代码库时，也保留完整库列表，防止模型外代码按名称动态选择组件而漏库。Hostless 库内部的跨库依赖依照 HostLessPackageInfo.deps 契约处理。

每个完成的模型事务重新计算选择；引用查询复用现有模型写入版本缓存，库请求仍捕获精确 pkgId/version。新增引用、升级、撤销和重做复用已有注册加载队列及渲染门控，避免组件先于注册就绪渲染。本优化减少首次执行和注册；不承诺删除引用后会立即回收已经执行的库代码。

**本轮对照。** 对照与正式实现只相差组件库选择相关的两个产品文件；基础 Host、canvas、ReactWeb 运行时 SHA-256 一致。环境同前轮：macOS 26.6.2、M4 24 GiB，Electron 45.2.1 / Chromium 156，React 19.3.1，运行时修订 a475f219bfae530ba61900e8e5b310020cbb8292。

两项目分别执行耗时和自然内存 ABBA；每臂两个进程，每进程六次打开、排除前两次预热。共 16 个进程、96 次打开，计时和内存各 32 个暖样本；表内为中位数。无 debugger、trace、强制 GC 或功能探针；额外内存轮在就绪后等待 1.5 秒取活动值，并以 100 ms 间隔采样打开期间峰值。正式自然进出均检查旧编辑器 PID 退出和 Dashboard 保留。

耗时是内部就绪/渲染标记，非 compositor 呈现或系统输入延迟。内存是包含诊断主进程、Dashboard、GPU、Utility 和编辑器的进程 working-set 之和，可能重复计算共享页，不是 macOS footprint、系统新增物理内存或存活 JS 堆。真实保存模型由离线后端回放，复杂样本来自真实发布 Site；不包括线上 API/IAM、业务网络和原生草稿 IPC 延迟。其他应用负载、系统缓存与热状态未受控。

**正确性验收。**

- 四个相关 Vitest 文件 57 项通过；最终依赖选择文件 17 项另行重跑通过。覆盖新增/删除引用、升级与撤销、默认/预览/fallback/虚拟插槽、未激活分支、TplRef、富文本、全局 Context、循环子组件、render-prop 类型、传递库依赖、动态全局表达式、Host/函数/代码库回退和延迟 UI 发布前的请求时序。
- GP 内置 Host：图标库启动时未安装，Studio 插入注册表仍包含该图标；插入条件为 false 的图标即补齐库；激活后检查连接在当前文档中的真实 SVG。条件撤销后模型值为 false，真实 Preview 不显示 SVG；重做后 Preview 显示 SVG。插入撤销/重做后，保留新增条件引用执行完整客户端保存，完整重载 Studio，再核对完整 bundle、修订、图标库和真实 SVG。
- 同源独立地址的自定义 Host：初始四库完整加载；HostDynamicIcon 根据字符串属性在运行时查注册表。模型没有指向该图标的 TplComponent 引用，仍能显示真实 SVG；插入撤销/重做、保留动态组件的保存与重开均通过，Host 提供的注册未被覆盖。
- 复杂十画板：首/中/末切换、图层树真实 DOM 重命名、实际 DOM 样式、画板位置编辑及撤销/重做通过；冷画板销毁后的选择与样式撤销/重做通过；完整保存重开后一致。对照构建两项目也各完成原有全流程。五份最终功能报告均无 renderer 错误、意外写入或缩略图错误。
- 完整 TypeScript 检查通过；三个相关产品/测试 TS 文件及新增驱动 ESLint 零错误零警告，三个诊断驱动 Node 语法检查及相关 diff 空白检查通过；两侧严格 React Compiler 生产模式构建通过。既有 open-functional / real-project-open 驱动的整文件 ESLint 仍有本次新增行之外的 curly/no-undef/no-shadow 问题，未扩展本次修改范围。

功能探针最初把撤销后设计画布的临时内容揭示误判为条件撤销失败；改为核对保存条件并在真实 Preview 检查 false/true，未修改产品的内容揭示策略。动态插入探针需要原生内容容器，因此用 GP 执行；复杂十画板单独执行其原有完整/冷恢复回归。
