# Studio 编辑、项目列表与导出复核

以 0.8.1 源码为前侧。Electron 45.2.1 用相同本地画板夹具对照，WAB 使用 Node 24.20.0、实际权限函数、实际草稿控制器和冻结业务模型。逐次样本见[对比数据](followup-comparison.json)。

## Desktop 草稿

只在前一份写入完成后为最新待写版本构建快照。同一序号和基线修订共享进行中的写入。写入失败可以重试，旧保存回执仍按序号保护较新的草稿。远端合并失败时丢弃待构建的请求，保留已经生成的最后一个有效快照，包含写入中的有效版本。

阻塞第一次写入并提交 11 次后续保存，阻塞期间构建快照 **12 → 1 份**，实际写入 **12 → 2 次**，序号为 1 和 12。最终最新快照可恢复。旧版前 11 个调用结束时，最新编辑尚未备份。新版共享这批写入结果。

冻结复杂模型单份草稿仍为约 6.74 MB。曾验证直接保存输入 JSON 能跳过一次编码，但已有原生测试要求持久化为规范 JSON，因此撤回该候选。依赖独立落盘需要设计崩溃恢复、旧文件读取和配额回收的原子边界。 [草稿控制器](../../../platform/wab/src/wab/client/studio-ctx/desktop-drafts.ts) · [恢复回归](../../../platform/wab/src/wab/client/studio-ctx/desktop-drafts.test.ts)

## Preview 预热

编辑器启动后不再自动为当前页面和链接页生成 Preview 代码。实际进入 Preview 后，当前页仍可与 Host 和组件库加载并行准备，已打开 Preview 的链接页预热继续可用。

原复杂冻结样本的后台任务中，根页面代码生成约 **25 ms**，一个链接页面约 **120 ms**。普通打开编辑器已移除这条执行路径。首次主动打开 Preview 可能承担此前已经完成的准备工作，本轮未做首次 Preview 的端到端计时。 [编辑器初始化](../../../platform/wab/src/wab/client/components/studio/studio-initializer.tsx) · [Preview 准备](../../../platform/wab/src/wab/client/components/live/live-syncer.ts)

## Dashboard 权限计算

同一列表响应的项目、工作区和团队权限只建一次索引。卡片仍调用原权限函数，直接权限、工作区和团队继承、父团队、匿名和其它账号的结果经对照验证。保留服务端鉴权。

每侧 12 个有效样本，计入索引建立，不含 DOM 和网络：

| 项目 / 权限行 | 全部卡片权限计算 p50，前 → 后 |
| --- | ---: |
| 100 / 601 | 3.97 → 0.27 ms |
| 500 / 3,001 | 73.78 → 1.05 ms |
| 1,000 / 6,001 | 286.63 → 1.94 ms |

全量卡片挂载和服务端分页需要独立的列表和搜索验收。 [项目卡权限索引](../../../platform/wab/src/wab/client/components/dashboard/project-card-permissions.ts)

## 画板读取与导出

全量布局按最多四张画板并行读取，维持原画板顺序。无节点条件的导出定位仅读取画板元信息。读图只收集可见图片，仍验证请求的图片在业务画布中。普通静态 HTML 直接使用已提取的文档。PDF 由 Chromium 打印，跳过位图捕获。元素裁切、位图格式和整页截图继续走各自的几何与像素路径。

原生夹具每板 241 个可读元素，导出 viewport 为 1,440 × 1,200。按 ABBA 执行，每组每侧 6 次有效样本：

| 路径 | 前 → 后 p50 |
| --- | ---: |
| 1 张画板完整布局 | 16.45 → 16.75 ms |
| 4 张画板完整布局 | 67.29 → 16.23 ms |
| 10 张画板完整布局 | 167.02 → 49.88 ms |
| 10 张中读取指定画板 | 16.94 → 17.15 ms |
| 普通静态 HTML | 91.89 → 16.54 ms |
| PDF | 132.03 → 118.46 ms |

原生 PDF 校验覆盖页数与尺寸，整页截图覆盖嵌套滚动与元素裁切。 [画板读取和导出](../../../desktop/src/canvas.cjs) · [原生 PDF 测试](../../../desktop/tests/canvas-pdf.cjs)

## 服务端增量保存

复用请求独享的上个修订模型表和已解析的输入，移除全模型表的一次浅拷贝。增量输入从解析三次收敛为一次，完整输入从两次收敛为一次。完整校验、事务、版本冲突检查和已保存修订格式继续执行。隔离 PostgreSQL 验证增量保存、完整保存和重复提交旧修订被拒绝。

冻结模型的合并、校验和 JSON 编码局部 p50 为 **4.64 → 4.13 ms**（1,420 个对象）和 **48.74 → 45.42 ms**（10,746 个对象），每侧 12 次有效样本，范围从 schema 预检之后开始。收益较小。缩减验证范围或改写修订持久化前，仍需要量线上数据库和事务等待，并验证旧模型及引用完整性。 [服务端保存](../../../platform/wab/src/wab/server/routes/projects.ts) · [数据库回归](../../../platform/wab/src/wab/server/routes/projects-save.test.ts)
