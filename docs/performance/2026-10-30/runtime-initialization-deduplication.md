# 画布运行时初始化去重

日期：2026-10-30。状态：实现、生产构建、本地签名打包、安装及功能验收通过，尚未发布生产版本。

## 当前加载契约

[`ensureCanvasRuntime(win)`](../../../platform/wab/src/wab/client/components/studio/studio-bundles.ts) 统一负责画布基础运行时的初始化。它按目标窗口的当前 `Document` 保存正在进行的 Promise，在异步工作开始前登记任务：

| 状态 | 行为 |
| --- | --- |
| 未开始 | 创建、登记任务，再获取并执行运行时源码 |
| 加载中 | 返回同一个 Promise，组件库等待它完成 |
| 已就绪 | 复用目标窗口的 `__CanvasPkgs`，不再获取或执行运行时源码 |
| 下载失败或超时 | 中止下载，清除下载缓存和各窗口任务，允许重试 |
| 执行失败 | 清除任务和未完成的运行时标记，允许重试 |
| iframe 重载 | 新 Document 使用新任务，旧下载不会注入替换后的页面 |

不同窗口各自执行运行时，保留自己的 React、Antd Context 和注册表。源码下载仍复用现有内存请求缓存；执行失败可复用已经取得的源码，下载失败则重新获取。

三分钟期限统一约束共享下载的响应头等待和正文读取。期限到达后中止请求并使共享 Promise 失败，不仅在调用端停止等待；所有等待者获得失败结果，后续调用可以创建新下载和初始化任务。

`getSortedHostLessPkgs(win, ...)` 和 `getHostLessPkg(win, ...)` 必须取得明确的目标窗口。组件库源码下载与必要的运行时初始化并行，初始化成功后只返回注册脚本，不在注册脚本中再次拼接运行时。库版本解析、注册排序、注册替换与回滚保持原有语义。

父 Host、画板、隐藏注册窗口、Preview、文档预览、仪表盘缩略图及组件库转换入口均使用上述契约。原有 `canvasRuntimeLoaded` 布尔参数已移除。脚本执行函数统一位于无额外依赖的 [`script-exec.ts`](../../../platform/wab/src/wab/client/script-exec.ts)，避免基础加载入口引入整个 DOM 工具模块。
