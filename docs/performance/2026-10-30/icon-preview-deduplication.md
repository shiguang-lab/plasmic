# 图标预览去重实施结果

日期：2026-10-30。状态：本地签名打包、安装及功能验收通过，尚未发布生产 App 或组件库。

## 行为

- Antd Icons 保留相同的 848 个图标、分组、官方实现、导入名称和原有 Props。注册不再生成 `thumbnailUrl`，生成目录只保存名称与主题，不再复制官方 SVG 路径。
- 组件目录从现有注册表取得图标实现，使用加载该注册的同一套 React/ReactDOM：平台库使用 Studio 的 `__Sub`，自定义 Host 注册使用父 Host 的运行时。图标保持紧凑卡片布局，复用现有虚拟列表的挂载范围，没有为每个图标增加 iframe，也没有将整套图标再次导入 Studio 主包。
- 默认预览通过实例 Props 设置主题主色和双色副色，不改变业务实例、注册定义或全局双色配置。Host 预览根在虚拟卡片卸载后释放；覆盖 StrictMode 的重建行为。
- 显式 `thumbnailUrl` 优先，外部 URL 与 data URL 按原图展示；加载失败时回退已注册 SVG，普通组件则使用默认占位。不会为了预览而自动运行普通业务组件。
- 注册已加载时使用当前缩略图配置；只有未取得注册时才读取保存的定义，防止新库取消默认缩略图后又回退到旧模型的内联 SVG。该预览选择本身不修改保存模型。
