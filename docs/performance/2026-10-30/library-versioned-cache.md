# 组件库独立发布与本地缓存

状态：模型资源化改造在源码中，尚未配套发布服务端和 App。生产仍运行 0.5.27 及历史列表服务端热修复，详见 [生产状态](../2026-10-31/unpublished-revisions-hotfix.md)。画布性能 A/B 和完整业务操作回归待配套环境验收。

## 当前实现

- 删除桌面本地构建的 `localCanvasLibraries` 覆盖。Antd6、Icons、Overseas、React UI 均按项目依赖中的包 ID 和精确版本加载；消费场景缺少依赖版本时报错，不请求 latest，不返回安装包代码。
- 库自身编辑/注册场景先通过 `/hostless-libraries/:name/release` 解析具体版本，再走相同制品加载路径。普通组件库发布继续使用已有 `publish-library.ts`，模型和代码在同一事务内保存；不要求重新构建 App。共享 React/Antd 和新增编辑器协议能力仍属于 App 更新范围。
- 修复 `getPkgVersionByProjectId` 的 latest 选择：使用现有版本解析器，避免无序数据库结果的最后一条被当成最新版。平台库自动升级的范围、大版本策略、已打开编辑器刷新提示、普通设计库接受更新和网站重发规则保持现状。

## 存储和网络契约

`desktop/src/library-cache.cjs` 只缓存版本化代码正文和依赖模型内容。目录按 Studio 来源、账号、实际 renderer 构建哈希隔离，代码键另包含库路径、包 ID 和精确版本。服务端返回独立浏览器源码 SHA-256，客户端核对包/版本及正文摘要；已有整份制品 digest 仍供发布器使用，不冒充浏览器源码摘要。

命中代码直接读磁盘，零网络校验；未命中通过现有认证下载。同一认证代次的并发 GET/HEAD 共用下载，错误、HTML、版本错配及不完整响应不入缓存。认证刷新后，新请求使用独立任务，不等待旧代次下载，也不会因旧任务失败而失败。缓存封装校验覆盖键、响应头和正文，临时文件原子替换；全局预算 256 MiB，优先淘汰未使用内容，活动读取/下载受保护。账号变化使未完成操作失效；退出清理全部组件库资源缓存，包括先前进程留下的账号/构建命名空间，不删除业务草稿。

模型按独立资源加载，不做客户端摘要协商：

1. 首次打开通过 `GET /api/v1/projects/:projectId?includeStartup=true`（另传 `branchName`）一次返回启动上下文、项目正文和依赖资源清单。专用 `editor-bootstrap` 接口已删除。启动上下文与项目数据并行读取，项目元信息和权限只读取一次；普通刷新不查询启动上下文。
2. 项目、包和历史修订 GET 按原逻辑鉴权、选版本、迁移及自动升级，固定返回项目正文和依赖元数据，依赖正文替换为 `modelResourceId`。这属于固定的资源拆分契约，不依赖客户端缓存状态。
3. SharedApi 并行 GET 当前响应引用的模型资源，交付编辑器前补齐完整模型。Desktop 的资源协议处理器先查账号/构建范围内本地文件，命中不访问服务端，缺失才网络 GET。项目打开、历史列表及原写入 POST 都透传，不修改请求方式或正文。
4. `GET /api/v1/dependency-models/:resourceId` 正常检查包权限，返回该资源完整 JSON，不接收库存或摘要列表。响应校验和只用于客户端下载完整性校验。
5. `dependency_model_resource` 保存迁移后不可变模型正文，按包发布实体和正文内容唯一。同一实体迁移后内容变化生成新资源 ID，已生成资源不覆写。普通读取事务先提交，再生成资源并提交，最后输出资源 ID，避免首次下载与事务提交竞态。

服务器端摘要仅用于去重不可变制品；客户端不把摘要传回服务端判断缓存。空缓存无特殊响应，按普通资源 GET 加载。首次生成制品有一次性入库开销；缓存全命中时无模型资源网络请求。实际请求数、开销和局限见 [模型资源化验收](../2026-10-31/model-resource-loading.md)。

## Web 与 App 统一缓存

`@plasmic-shared/resource-cache` 为两端提供相同的不可变资源匹配、SHA-256 校验、并发去重、账号切换拦截和失败重试规则。App 使用主进程文件存储；Web 使用页面内 CacheStorage，不注册 Service Worker。App 前端直接交给原生协议，避免重复落盘。两端均不缓存项目正文或权限，版本选择继续由实时接口决定。完整契约和验证见 [统一缓存层](../2026-10-31/unified-resource-cache.md)。
