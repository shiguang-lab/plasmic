# 灵动岛状态传输与退出资源释放

状态：Desktop 源码已实现并通过本地测试，未发布或安装到用户 App。范围仅为灵动岛的状态/图片传输和模式生命周期；不修改 Web、服务端、组件库缓存或自动升级策略。

## 当前行为

- 启用时保留 500ms 状态/截图检查和 40ms 鼠标命中检测，以及现有动态画面刷新和任务反馈规则。
- 发送前比较不含图片正文的状态。内容完全相同时不发 IPC；图片正文相同时仅发送图片元数据和反馈，接收端复用已有像素。图片变化时发送正文，显式 `image: null` 清除旧图。
- 切回普通窗口或全屏时，清除三组定时器，销毁浮窗及截图合成窗口，清除最后截图缓存和传输去重状态。
- 停止灵动岛专用账户摘要请求；普通窗口中的导航不会再发起这些请求。账户读取的结果按生命周期隔离，旧响应不能覆盖重新开启后的数据。共享身份读取不被灵动岛退出取消，避免影响其他消费者。
- 主题、语言、更新和任务事件的应用订阅仍由现有宿主管理；非灵动岛模式在生成 snapshot/发送 IPC 之前返回，不创建新的页面工作。实际 MCP、保存、更新和工作区持久化继续运行。
- 再次开启时创建新浮窗，从当前 URL、账户及编辑器上下文重新同步，再生成画面。进行中状态/截图任务有独立标记，旧任务结束不会解除新任务的进行中标记。
- 保留“显示主窗口”与“显式退出灵动岛”的关闭偏好差异、全屏切换、macOS Dock/焦点及重启恢复。

退出模式与收起卡片不同：收起卡片仍保留本次会话的图片缓存和选中画板范围，用于快速展开；退出模式会清除图片缓存并释放浮窗。

主要实现位于 `desktop/src/island.cjs`、`island-account.cjs`、`island-capture.cjs` 和 `island-renderer.js`。

## 验收

结果记录见 [JSON](island-state-lifecycle-acceptance.json)。本机使用 Electron 44.5.1 / macOS；未在 Windows/Linux 或受影响低端设备上测量 CPU、RAM。

| 检查 | 结果与边界 |
| --- | --- |
| `node --test tests/island-*.test.cjs` | 57/57 通过；覆盖账户请求取消、像素复用、反馈更新、退出静默、反复开启、旧异步结果隔离及任务保留 |
| `electron tests/island-native.cjs` | 真实 Electron 窗口、IPC、stdio MCP 的 16 组场景通过；编辑器和网络使用确定性 fixture |
| 静止 IPC | native fixture 中等待稳定后观察 1.1 秒，状态推送增量为 0；不代表 CPU 使用率为 0 |
| 任务中退出 | 实际 stdio MCP read 在退出后正常完成；退出后的任务事件和普通窗口导航无灵动岛状态推送、无新账户摘要请求，浮窗不再存在 |
| 退出和重新开启 | 覆盖普通窗口/全屏/灵动岛快速切换、重建后的当前画面、登录状态、主题/语言、更新状态及保存/预览行为 |
| `node tests/close-mode-native.cjs` | 匹配的隔离 App 副本中 5 个阶段全部通过：choose、window-reopen、reopen、exit、quit；覆盖关闭选择、冷启动、Dock/重启唤起和浏览器登录回调 |
| 静态检查 | 修改的四个运行文件 `node --check` 及 `git diff --check` 通过 |

本机现有 `desktop/renderer` 是 0.5.27 本地资源，与当前配置要求的 0.5.30 不匹配。关闭模式验收首次被现有启动保护拦截，未进入功能阶段；随后使用正式 0.5.30 App 资源建立临时副本，覆盖当前 Desktop 源码和测试、复用本机依赖，完成上述 5 阶段验收。没有修改匹配检查或用户安装的 App。

同机固定页面的修改前后测量见 [收益对照](island-state-lifecycle-benefits.md)：退出后释放一个浮窗渲染进程，停止专用摘要调用，静止状态不再重复推送；重新开启约增加 0.15 秒。该 fixture 的 CPU/RSS 结果不代表真实项目或低端机收益，不使用“内存减半”作为结论。
