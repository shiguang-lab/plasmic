在本次代码审核和下列自动化检查范围内，未发现未解决的阻塞发布问题。生产服务和已安装 App 未改动。

## 已修复问题

| 问题 | 当前实现及验证 |
| --- | --- |
| 并发模型请求共用错误响应体，后一个消费者无法读取错误；HEAD 带回错误正文 | 每个消费者取得独立响应，HEAD 无正文，保留 HTTP 状态和响应头；覆盖 401、403、404、500、503，失败不入缓存且可重试。真实 Electron 另验证并发 gzip 403。 |
| 304 提前结束 HTTP 请求，读取事务仍未完成 | 事务完成后才发送无正文响应；提交失败时不发送 304，恢复原响应方法并交给错误处理。真实 PostgreSQL 发布测试正常收尾。 |
