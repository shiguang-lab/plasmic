# 画布前端优化验收

本轮完成查询内尺寸缓存和多选拖拽落点扫描去重。正式代码没有新增依赖、持久化状态或跨查询缓存。结果为离线真实项目回放，未打包安装或发布。完整脱敏统计、源码指纹及各进程结果见 [JSON](frontend-optimizations.json)。

## 实现

`GeometrySnapshot` 在一次同步只读查询中复用 `offsetWidth/Height`、`clientLeft/Top/Width/Height`，用于祖先 padding box 和画板视口计算。矩形、样式及尺寸均随查询结束释放。下一次滚动、编辑、撤销或框选重新读取；不跨帧保留 DOM 测量。裁剪的包含块判断、变换换算、各轴规则和选择顺序代码未改动。未传入快照的悬浮、揭示等调用仍即时测量。

`DragMoveManager` 收集完全部对象和组合鼠标偏移后，构建一次 `NodeTargeter`。之前每个对象都扫描一遍同一画布，只有最后一套结果会使用。多选现在与单选一样只生成一套源画板落点；跨画板目标仍各自构建。没有重写移动、放置、取消、撤销或保存流程。

## 几何增量对照

基线为本轮修改前已经具备矩形和样式缓存的实现，**不是最初无缓存的算法**。基线的选择函数、快照和裁剪函数分别冻结，避免让旧算法误用新缓存。两组在同一个构建中运行。

Apple M4、24 GiB、Electron 44.5.1。单位 ms；表内为独立进程中位数的中位数。GP 各三进程，十画板控制场景各六进程，每进程预热 8 次、计时查询 32 次及原生框选 12 次。

| 场景 | 实现 | 几何查询 | 框选反馈 |
| --- | --- | ---: | ---: |
| GP | 原缓存版 | 119.75 | 178.25 |
| GP | 补充尺寸缓存 | 47.40 | 99.55 |
| 十画板控制场景 | 原缓存版 | 0.60 | 62.72 |
| 十画板控制场景 | 补充尺寸缓存 | 0.50 | 63.12 |

GP 查询减少约 **60.4%**，反馈减少约 **44.2%**。三轮反馈 p95：原缓存 201.7 / 190.9 / 181.9，候选 120.8 / 117.1 / 124.9。

控制场景的查询本身不足 1 ms，没有建立交互提速结论。首批候选的一个进程反馈明显偏高，但查询仍不足 1.2 ms，因此额外执行三组交替顺序轮次；全部六轮均保留。两组后续也都出现尾延迟波动，不能把差异归于缓存。六轮反馈 p95 分别为原缓存 63.3 / 63.5 / 72.0 / 90.3 / 101.2 / 101.3，候选 67.4 / 111.4 / 66.5 / 65.6 / 95.0 / 93.6。

合计 **576 次计时查询、216 次原生框选**，完整选择标识集合及查询选择数序列一致。已查看 GP 原版/候选截图，选中 7 个图层、选框及业务布局一致。

反馈指标从可信 pointerup 捕获到求值完成及两次 rAF，不包括 OS 输入排队和屏幕呈现，不代表平移缩放 FPS。计时前等待全部初始画板完成渲染。发现与其它诊断进程重叠的轮次单独保留并重跑。

## 多选拖拽启动对照

使用同一真实 GP 模型和 DOM，比较正式类与冻结的原类。每组各三次新进程，每个对象数量预热两次、测量六次。为隔离属性面板选择带来的布局工作，诊断入口直接传入真实对象并提供拖拽影子元素；不改变属性面板选择。

| 对象数 | 原构造耗时 / ms | 优化后 / ms |
| --- | ---: | ---: |
| 1 | 56.60 | 56.95 |
| 3 | 185.55 | 64.65 |
| 6 | 422.90 | 78.90 |

三个和六个对象的启动计算分别减少约 **65.2% / 81.3%**，单选基本不变。这是构造耗时，不是原生拖放全流程延迟。

三个规模的全部节点/插入区域、几何坐标、接受规则、布局方向及最终鼠标偏移摘要在六个进程间一致；每轮取消后完整保存模型不变，站点不变量通过，浏览器错误数为零。最初含无效槽位探测和属性面板反复切换的试验在原版基线上失败，并记录 ResizeObserver 错误；两版试验构建及日志分别保留在私有目录，不进入有效统计，也没有过滤浏览器错误。最终入口仅测量构造、落点数据及取消，没有建立原生多选移动/提交的端到端性能覆盖。

## 功能与内存

- 七个相关 Vitest 文件 **57 项通过**，覆盖框选、裁剪、缓存刷新、变换和边框、视口变化、fixed/absolute 包含块、单选/多选鼠标偏移、空选择、落点规则、跨画板最终位置和 Escape 取消，以及现有画板活动状态。
- 完整 `pnpm --dir platform/wab typecheck --incremental false` 通过；隔离生产模式构建通过，正式源码指纹与最终测试副本一致。
- 最终构建中 GP / 十画板分别通过 **12 / 11 类几何场景**，另通过 **11 项功能检查**，覆盖画板切换、真实 DOM 编辑恢复、撤销重做、GP Preview 分页及两份完整模型保存后重新打开。保存和重开均使用隔离内存服务，没有写入真实后端。
- GP 每组两次新进程、每进程 240 次查询。原缓存 renderer RSS 峰值为 1533.28 / 1167.59 MiB，候选为 1138.84 / 1146.95 MiB；诊断 GC 后 V8 heap 分别为 120.30 / 120.48 和 120.22 / 120.31 MiB。没有观察到持续堆增长；RSS 进程间波动较大，不认定稳定内存节省。计时轮不执行强制 GC。
