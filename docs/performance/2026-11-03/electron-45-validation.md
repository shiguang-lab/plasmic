# Electron 45.2.1 升级验证

桌面端精确依赖从 44.5.1 升至 45.2.1，更新 `desktop/package.json` 和 `desktop/package-lock.json`；未引入运行时兼容分支。Desktop 不在根 pnpm workspace 内，已有独立 npm 锁文件，测试和发布 CI 均使用 `npm ci --prefix desktop`。

## 性能

macOS arm64，固定同一份前端资源、Desktop 产品实现及真实项目离线载荷。按 44 / 45 / 45 / 44 顺序串行启动独立进程，每组分别运行 GP 单画板及复杂十画板项目六次；前两次预热，后四次计时，每版本每项目八个计时样本。不开 debugger、trace、诊断 GC；不包含线上 API、IAM 或业务服务耗时。启动使用生产 main/preload 和全新隔离 profile，每版本六次，父进程记录 Electron 启动前时间，终点是项目列表卡片 DOM 就绪，不是合成器呈现。

| 指标（中位数） | 44.5.1 | 45.2.1 | 变化 |
| --- | ---: | ---: | ---: |
| 启动至项目列表卡片 | 1,561 ms | 1,696 ms | 慢 8.6% |
| GP 首画布就绪（轮询） | 1,934 ms | 1,944 ms | 慢 0.5% |
| GP 全画板就绪（Studio mark） | 1,792 ms | 1,797 ms | 慢 0.3% |

操作系统文件缓存未受控，首次运行均有较大离群值；此测量不能证明严格冷启动收益或稳定的总体性能提升。两个版本的 renderer console error 均为零；各组离线缩略图夹具均有七次既有错误，不能将其计为缩略图功能通过。逐轮脱敏数据、资源指纹及夹具 SHA256 见 [测量数据](./electron-45-measurements.json)。
