通过 MCP 连接 Plasmic Desktop

将 Plasmic 的画布能力连接到外部 AI 工具。启用下方客户端后，即可通过 MCP 读取设计、生成原型、修改组件并保存到 NAS。使用时请保持桌面应用运行，并登录打开需要编辑的项目。

›_自定义 MCP 服务器配置

如果使用其它支持 MCP 的工具，可以复制以下配置并添加到该工具的 MCP 服务器配置中。Codex 和 OpenCode 的配置格式由上方开关自动处理。







图像服务
用于 MCP 图片生成、编辑、去背景和替换背景。服务需支持 Images API；密钥只保存在本机，不会发送给 MCP 客户端。
