# Plasmic Desktop 0.0.25

- Download updates automatically in the background and show an installation prompt when the verified download finishes.
- Review installed and new versions, release notes, download progress and retry actions in the new Software Update window, with light and dark themes.
- Use the compact sidebar button to reopen the update window. The icon changes when an update is ready and expands to Update on hover or keyboard focus.
- Find Check for Updates in the macOS Plasmic menu directly below About Plasmic.
- Choose Restart and Install to save the current design before restarting, or Later to keep working. A failed save prevents installation.
