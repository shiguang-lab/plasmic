# Plasmic Desktop MCP design workflow

1. Start the desktop and sign in. Call get_app_state for readiness, active project and exact validated editor schemas. list_projects and open_design select an accessible NAS project.
2. execute identify checks edit permission. execute read without arguments lists project resources, tokens and components. Read imported Ant Design 6 component UUIDs to obtain exact props, events and slots. Never assume Ant Design 5 contracts.
3. Create a page with createComponent. Insert semantic HTML and registered components with insertHtml; preserve UUIDs returned by the operation. Use changeElement for props/layout, insertHtml replace for text and slot content, deleteElement for nodes. These operations use Studio transactions and remain editable.
4. HTML code components use <plasmic-component data-plasmic-component="REGISTERED_NAME" data-plasmic-project="IMPORTED_PROJECT_ID" data-props='{"size":"medium"}'><slot name="children">Content</slot></plasmic-component>. Read contracts to obtain names and supported values. Use data-plasmic-name for meaningful element names. Do not insert script tags or invent native input handlers.

For admin/list query regions, use Overseas `plasmic-overseas-search-form` with editable `plasmic-overseas-search-form-item` nodes in its children Slot, rather than constructing a native query grid. Read the installed Overseas contracts first; install/upgrade its published library when SearchForm is absent. Put exactly one Antd6 input control in each Item's children Slot. Configure unique name, label, span, initialValue, clearValue and validation on the Item; configure placeholder/options/date mode on the actual control. Default list layouts use colSpan=6, minRows=1 and marginBottom=0 when the parent already owns spacing. Additional actions go in extraActions; rich labels/help use labelContent/help Slots. Items remain editable through insertHtml, changeElement, moveElement and deleteElement. Bind onSearch(values) and onReset(values) to applied filters and reset pagination to page one; keep draft values separate. The form exposes readonly values, writable collapsed and submit/reset/setFieldsValue actions. Editing shows all fields; runtime collapse retains every field's value. See docs/search-form.md for the complete contract. Do not put React elements in a JSON fields array or duplicate built-in query/reset buttons.
Button icons must be independent SVG Icon nodes, using the Button icon Slot and iconPlacement for a leading/trailing icon. Use official Ant Design icon geometry and currentColor. When a trigger needs both a leading action icon and trailing dropdown indicator, place the action icon in icon and the indicator beside the label as another Icon node. Never imitate icons with Unicode characters inside button labels, such as ＋, ⌄, ‹ or ›. Verify the delivered page's actual icon nodes and dropdown behavior.

5. createState adds typed reactive state; bindings use {{ $state.name }}. createInteraction attaches supported events and state actions. get_style lists local design presets with palette, typography and spacing. createStyleToken creates reusable design tokens. execute_batch validates all operations before applying one atomic Studio transaction; any failure rolls back the whole batch. undo reverts the entire batch. Targets must already exist; use separate calls when subsequent operations need newly created UUIDs.
6. validate checks structural invariants, not visual quality. snapshot_layout reads actual rendered geometry and image sources for the open page. It returns bounded DOM observations, not editable model IDs; execute read provides those UUIDs. Check desktop/mobile screenshots and overflow. Do not claim quality from a validation count.
7. get_screenshot returns clean static artboard pixels by default, without editor chrome or empty slot placeholders. width selects the closest existing frame and sizes its rendered snapshot. Use existing frame widths when checking responsive variants. mode workspace shows the visible editor; rect requires workspace mode. Static snapshots do not execute prototype interactions.
8. import_image uploads an explicit absolute local raster file to NAS storage and returns src/width/height. It converts to PNG and does not preserve animation. Use that source in a registered Image component via insertHtml or changeElement. read_image returns PNG pixels from an exact image src observed by snapshot_layout. Sources not present in the design are rejected. Raster data URLs and authenticated NAS images are supported, up to 10 MiB; vector sources require a screenshot.
9. export_design saves static PNG, JPEG, WebP, PDF or HTML at an absolute outputPath with a matching extension. Files are never overwritten. HTML includes rendered markup and CSS, has scripting disabled, and is not editable React source or an interactive standalone app. Image links may still refer to NAS/external assets. PNG/PDF embed the rendered visual. Save editable project data with execute save.
10. Call save explicitly, then reload/reopen and read to confirm persistence. Only report actual success. Keep new acceptance pages separate from existing user work.

11. copyElement and moveElement operate within a component; queryElements searches real model nodes. updateState/deleteState and updateStyleToken/deleteStyleToken modify local variables. Create component variant groups/options, global theme groups/options and screen breakpoints; variant-specific changeElement styles use their returned UUIDs. visibleIf and repeat use validated {{ JS }} expressions. deleteComponent rejects referenced components.
12. get_screenshot elementUuid crops visible nodes. browser maintains an isolated reference page for load/capture/CDP interactions; only the reference page is accessible, never the Studio debugger. capture_browser captures an HTTP(S) reference page or selector as PNG and sanitized styled HTML; insertHtml can import that HTML. make_vector authors SVG paths and boolean geometry, optionally importing an SVG asset. SVG assets are replaced as source, not edited as native Studio path nodes.
13. export_pages combines ordered artboards into one PDF. export_code saves editable React/TypeScript/CSS and the complete NAS codegen bundle in a new directory; dependency installation and compilation remain separate.
14. generate_image supports generate/edit/remove_background/replace_background. Configure the service in MCP → MCP 设置… → 图像服务. It requires image-service.json in the desktop user-data directory with baseUrl (Images API base, e.g. https://api.openai.com/v1), model and apiKey. Choose a service/model supporting the requested action. Returns a new PNG plus pixels; import_image inserts it into the design. Never disclose keys. No provider is configured by default.

vectorize_image locally traces raster files to SVG assets (at most 1 megapixel, best for flat artwork). search_stock_images returns Commons raster assets with license/source/attribution; preserve those requirements when using an asset. readVector returns SVG source and asset identity; updateVector edits sanitized geometry while preserving node/asset IDs (shared asset references update together). createCanvas/createArtboard create native freeform canvases at real viewport sizes; findEmptySpace finds non-overlapping positions in four directions; navigateCanvas selects that canvas/frame before snapshots. Native Studio normalizes canvas origin after placement, so read returned coordinates. Cross-component moves and editing descendants of opaque third-party React components remain governed by Studio component/slot contracts. Built-in AI is a later scope. Report verified behavior and limitations explicitly.
