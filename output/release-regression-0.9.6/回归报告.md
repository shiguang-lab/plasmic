# Plasmic 0.9.3 至 0.9.6 发布回归

2026 年 11 月 19 日（上海时间）。线上对象为 NAS Studio 与桌面更新源 0.9.6、实际安装的 macOS 桌面端 0.9.6、CLI 与设计资源 0.9.4。仓库 HEAD 比发布标签多一项桌面指南修改。

## 结论

NAS 生成封面、项目保存触发、查看权限、组件检索、页面设置以及 CLI 升级均通过相应回归。用户侧有两处异常，分别发生在桌面 MCP 读取编辑器状态和大文件下载时。

| 项目 | 现场证据 | 影响 |
| --- | --- | --- |
| Desktop MCP 间歇性超时 | 首次打开“海外 O 端”时，画布已显示，约 120 秒后仍返回 `Design did not become ready`。后续读取状态返回 `Editor command timed out: metadata`。另一次在临时项目里，显式保存命令在执行前遇到相同的状态检查超时；已提交的编辑随后由自动保存持久化。重新载入窗口后恢复，后续三次打开模板均成功（4.26、4.02、3.01 秒）。 | 在出现该状态的会话中，AI 无法可靠读取或操作画布。根因未确认。发生超时后，应先核对保存状态和持久化版本，再决定是否重试写入。 |
| 桌面安装包下载中断 | 从线上更新源并发做四个包的单请求全量下载，Windows 完成；Mac ARM 与 Linux 遇到 HTTP/2 流中断，Mac Intel 达到测试的 900 秒上限。三者改用校验 Content-Range 的分段请求后，全部完整下载。 | 下载链路在本次环境中有中断。四个文件均通过更新源 SHA-512 与 GitHub SHA-256 校验。此次结果无法定位中断发生在客户端、代理、网关还是上游。 |

## 功能覆盖

| 功能 | 验证方式与结果 |
| --- | --- |
| 发布及更新 | 四套安装包均从实际更新源取得并校验完整字节。Mac ARM 187,260,512 B，Mac Intel 194,395,917 B，Windows 164,667,830 B，Linux 194,113,195 B。Electron 原生更新测试通过差分重建、下载中断恢复及更新 UI 等 8 项检查。实际运行的发布客户端为 Mac ARM。 |
| 项目列表与封面权限 | 线上已登录 Chrome 的六张可见卡片均加载出 640 × 360 封面。最大项目已有封面经 NAS 内部读取四次，文件内容和修改时间相同。公网健康检查返回 200，匿名请求私有封面返回 401，直接打开截图页和模型均返回 403。 |
| 保存后自动生成 | 在个人工作区的专用临时项目新增页面与内容，再从网页页面设置将路由改为 `/cover-check-verified`。数据库证实主分支修订 5 和 6 已持久化，对应的封面分别在提交后 62.35 秒和 52.80 秒落盘。修订 6 已保存且新图尚未落盘时，修订 5 的封面仍在。5 分钟连续编辑上限、按项目合并、串行调度、失败重试和新修订接管另外由队列测试覆盖。 |
| 完整画布与故障恢复 | 用正式镜像启动 NAS 隔离 worker，单独挂载测试输出目录，加载最大项目修订 577 的全部 4 个画板。输出 11,232 B WebP。写盘被拒和 Chromium 被终止时分别返回 500，两次均校验旧封面 SHA-256 完整；恢复后下一次生成 11,266 B WebP。此轮隔离容器限 2 核，未将此轮用时作为线上性能基准。 |
| 组件检索 | 已安装的 Desktop 对临时项目执行只读复用检查，结果为 completed，索引覆盖 2/2。另在 NAS 的正式服务端镜像运行全 Material UI 库的原生模型测试，8 条中英文查询的首选全部匹配，覆盖侧边编辑抽屉、滑动导航、单值和区间滑块、Tabs、Table。缓存、账号/项目隔离与无效目录处理由自动化测试覆盖。 |
| 模板与页面设置 | 线上导航首项为模板中心，可找到“海外 O 端”。桌面端恢复后确认只读权限和发布版本 4.0.1，成功读取全部 17 个页面的名称、路径与描述，并按指定页面截取“资源查询列表”。网页临时项目的页面设置可打开，编辑后的路由已保存到新修订。模板目录元数据与画布独立发布、页面设置的主字段和搜索分享区另由自动化测试覆盖。 |
| CLI 与工作流资源 | 在隔离容器，从实际 npm 包模拟旧版本附带的 CLI 0.9.0 升级到 0.9.4，并使用迁移后安装的启动器。另从 NAS 下载并校验发布的 CLI，分别解析 inspect、prototype、codegen，所有必读文件存在且使用同一 releaseId。后两次命中缓存，显式 --refresh 后检查时间更新。 |

## 自动化与边界

桌面端 Go 测试通过，Node 测试 657 项通过。Studio/WAB 两轮共 12 个测试文件、107 项通过。CLI 与封面队列合计 53 项通过。NAS 的 Material UI 检索测试包含 8 条查询断言，均通过。Electron 原生更新检查单独运行通过。

本次完成了四平台安装包的传输与完整性核验，未在 Windows、Linux、Intel Mac 真机上进行手工安装或启动。模板管理写入由自动化覆盖。线上角色权限配置的完整组合未逐项验证；发布中的业务模板未被修改。测试项目已从个人项目列表删除，原拥有者再访问其封面返回 404。已清理其测试封面、隔离容器及临时下载分片。
